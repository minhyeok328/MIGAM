# 미감(美感) Domain Rules

## 1. 문서 목적과 권위 경계

이 문서는 에이전트와 구현자가 전시·작품·기관·방문 정보의 의미를 임의로 해석하지 않도록 도메인 용어와 불변식을 정의한다. 사용자 기능은 PRD, 저장 구조는 데이터 모델, 원본 변환은 정규화 규칙, 추천 점수는 추천 명세가 정한다.

이 문서에서 `공식`은 정부·지자체·공공기관·주최 또는 운영 기관이 자신이 책임지는 사실을 직접 제공했음을 뜻한다. 공식이라는 이유만으로 모든 필드가 최신이거나 서로 충돌하지 않는다고 가정하지 않는다.

## 2. 핵심 객체와 제품 내 우선순위

### Exhibition

정해진 기간과 장소에서 관람할 예술 콘텐츠를 공식적으로 구성·운영하는 단위다. 미감의 추천, 검색, 비교, 방문 판단의 주 객체다.

### Artwork

작가 또는 제작 주체가 만든 개별 작품·소장품이다. 공식 데이터가 충분한 범위에서 취향 탐색과 유사 작품 발견을 지원하지만 모든 전시에 작품 목록이 있어야 하는 것은 아니다.

### Institution

전시를 운영하거나 작품을 소장하는 공식 기관·공간이다. 기관 하트는 기관 선호 신호이며 해당 기관의 모든 전시·작품에 대한 포괄적 선호를 뜻하지 않는다.

### Creator

작품 또는 전시에 공식적으로 연결된 작가·제작자·참여 주체다. 이름이 등장했다는 사실만으로 특정 작품의 출품 또는 전시의 주최 관계를 추론하지 않는다.

### Source

사실값을 제공한 공식 데이터 또는 공식 페이지다. 화면에 표시되는 핵심 값은 내부적으로 Source와 확인 시각에 연결될 수 있어야 한다.

## 3. 전시 포함 범위

### 3.1 핵심 전시

- 국공립·사립 미술관과 박물관의 전시
- 상업·비영리 갤러리 전시
- 문화재단·공공문화공간 전시
- 비영리·대안예술공간 전시
- 회화·조각·공예·사진·디자인·건축 전시
- 사운드·영상·설치·퍼포먼스·인터랙티브·미디어아트 전시

### 3.2 확장 전시

다음은 전시로 다룰 수 있지만 핵심 전시와 다른 행사 형식을 명시해야 한다.

- 비엔날레·트리엔날레
- 아트페어
- 몰입형 상업 전시
- 일러스트·캐릭터 전시
- 브랜드가 기획한 문화예술 전시
- 축제 안의 독립된 전시 프로그램

### 3.3 제외 대상

- 상품 판매가 중심인 일반 팝업스토어
- 포토존만으로 구성된 이벤트
- 전시 콘텐츠·장소·기간·주최를 공식적으로 확인할 수 없는 홍보 행사
- 콘서트·뮤지컬·연극
- 강연·교육 프로그램만 있는 행사
- 공식 SNS 게시물 외에 확인 가능한 개최 근거가 없는 행사

### 3.4 경계 판정

다음 근거를 종합하며 제목의 `전시`, `아트`, `팝업` 같은 단어만으로 판정하지 않는다.

1. 감상할 작품 또는 구성된 콘텐츠가 존재한다.
2. 작가·기획자·제작자 또는 책임 주체가 확인된다.
3. 관람 장소와 기간이 정해져 있다.
4. 공식 기관 또는 주최 출처가 있다.
5. 상품 판매보다 감상 경험이 핵심이다.

## 4. 지역과 커버리지

`대한민국 전역 지원`은 지역 체계가 전국 시·도·시·군·구를 수용한다는 뜻이며 모든 지역 데이터가 완전하다는 뜻이 아니다. P0 품질 보장은 서울·경기·인천과 확인된 타 지역 데이터에서 시작한다. 데이터가 적은 지역은 커버리지를 과장하지 않는다.

## 5. 서로 독립적인 세 상태축

생명주기, 최신성, 노출 적격성은 서로 다른 질문에 답한다. 하나의 `status` 값으로 합쳐서는 안 된다.

### 5.1 ExhibitionLifecycle

| 값 | 의미 |
| --- | --- |
| `UPCOMING` | 공식 시작일이 현재보다 뒤이며 취소가 확인되지 않음 |
| `CURRENT` | 현재가 공식 시작일과 종료일 범위 안에 있고 취소가 확인되지 않음 |
| `ENDED` | 공식 종료일이 지났거나 종료가 공식 확인됨 |
| `CANCELED` | 취소가 공식적으로 확인됨 |
| `UNKNOWN` | 핵심 기간 또는 개최 상태를 신뢰성 있게 판정할 수 없음 |

`CURRENT`는 특정 날짜의 개관·회차·잔여석을 보장하지 않는다. 정기 휴관, 임시 휴관, 회차 예약은 별도 방문 정보다.

### 5.2 FreshnessStatus

| 값 | 의미 | 일반 처리 |
| --- | --- | --- |
| `FRESH` | `CURRENT` 또는 시작일까지 7일 이하인 `UPCOMING`은 마지막 성공 공식 확인이 48시간 이내이고, 그 밖의 `UPCOMING`은 3일 재확인 기한 안에 공식 정보를 확인함 | 검색·추천 정상 후보 |
| `STALE` | 마지막 공식 값은 있으나 재확인 기한을 넘김 | 검색 유지, 경고, 추천 순위 하향 또는 방문 조건별 제한 |
| `UNVERIFIED` | 최소 품질 핵심 항목의 마지막 검증 근거는 남아 있지만 반복 재확인 실패나 공식 페이지의 일시적 소실로 최신 방문 가능성을 신뢰하기 어려움 | 최소 품질 게이트를 계속 통과한 `DISCOVERY_ONLY`만 홈·개인화 추천에서 제외하고 확인 필요 검색 허용 |

### 5.3 DataEligibility

| 값 | 의미 |
| --- | --- |
| `VERIFIED` | 최소 품질 게이트를 통과했고 현재 정본이 제공하는 방문 정보가 공식 근거로 확인됨 |
| `PARTIAL` | 최소 품질 게이트는 통과했지만 일부 선택 방문 정보가 `UNKNOWN`임 |
| `DISCOVERY_ONLY` | 최소 품질 게이트는 통과했지만 최신성·충돌·노출 정책 때문에 일반 추천에서 제외하고 제한된 검색·발견에만 사용 |
| `EXCLUDED` | 최소 품질 게이트 미달, 공식성·권리·핵심 사실 오류 또는 정책상 비노출 사유가 있음 |

`PARTIAL`은 자동으로 추천 가능 또는 불가능을 뜻하지 않는다. 사용자가 정한 필수조건과 `UNKNOWN` 필드의 종류를 함께 판단한다. 최소 품질 핵심 항목이 미달한 레코드는 `PARTIAL`이나 `DISCOVERY_ONLY`로 사용자 검색에 노출하지 않고 원본 격리·운영 검토 대상으로 둔다.

### 5.3.1 기관 수집 health와 사용자 데이터

InstitutionAllowlistEntry의 `HEALTHY`·`DEGRADED`는 lifecycle이나 전시의 DataEligibility를 대신하지 않는 staff 운영 신호다. 첫 최종 수집 실패 또는 선택 필드 구조 문제로 `DEGRADED`가 되어도 마지막 정상 정본을 자동 삭제하거나 모든 레코드를 사용자 응답에서 일괄 제외하지 않는다. 각 레코드는 최소 품질·최신성·권리·충돌 규칙으로 다시 판정한다.

선택 필드 구조 문제가 원인이면 해당 요금·예약·관람시간·접근성·감각·미디어 값을 `UNKNOWN` 또는 이미지 대체 상태로 표시한다. 사용자는 기관 health 문자열 대신 기존 `확인 필요`, 마지막 확인 시각과 공식 링크를 본다. 단일 전시의 핵심값 예외는 그 레코드만 `EXCLUDED`로 격리하고, 기관·템플릿 수준의 반복 패턴이 아닌 한 기관 health와 lifecycle을 바꾸지 않는다.

기관이 `SUSPENDED`되거나 Critical 문제가 확인됐다는 사실만으로 마지막 정상 정본의 DataEligibility를 일괄 `EXCLUDED`로 바꾸지는 않는다. 마지막으로 확인된 핵심 사실은 기존 근거와 최신성 기한에 따라 다시 계산하고, Critical 근거가 현재 정본의 핵심값 자체를 신뢰할 수 없음을 보여주는 영향 레코드만 즉시 `EXCLUDED`로 격리한다.

### 5.4 전시 데이터 최소 품질 게이트

전시 한 건은 다음 항목이 모두 공식 근거로 확인되어야 최소 품질 판정 `CORE_PASS`를 받는다.

1. 전시명
2. 시작일
3. 종료일
4. 개최 장소
5. 개최 장소의 행정 지역
6. `UPCOMING`, `CURRENT`, `ENDED`, `CANCELED` 중 신뢰성 있게 판정된 유효한 생명주기 상태
7. 전시 단위의 공식 상세 URL
8. 해당 사실을 책임지는 공식 출처

`UNKNOWN` 생명주기, 누락되거나 역전된 기간, 장소 또는 지역 미확인, 공식 상세 URL이나 공식 출처 미확인은 게이트 불합격이다. `ENDED`와 `CANCELED`는 사실로서 유효한 상태이므로 게이트에는 합격할 수 있지만, 현재 추천 포함 여부는 6절의 생명주기 규칙이 별도로 제한한다.

요금, 예약, 예상 관람시간, 접근성, 감각 정보는 최소 품질 게이트의 합격 항목이 아니다. 확인되지 않은 값은 내부적으로 `UNKNOWN`을 명시하고 사용자 화면에서는 `확인 필요`처럼 의미가 같은 문구로 표시할 수 있다. 누락값을 평균, 유사 전시, 기관 일반 정보 또는 다른 분류축으로 추론해 채우지 않는다. 이 선택 정보가 `UNKNOWN`이어도 기본 게이트에는 합격할 수 있지만, 요청에서 해당 값이 필수 방문 조건이면 충족으로 간주하지 않는다. 예약·예상 관람시간을 선호로 선택하면 Preference이고, 필수로 명시한 요청에서만 Hard Filter다.

## 6. 현재 추천과 아카이브

| 영역 | `CURRENT` | `UPCOMING` | `ENDED` | `CANCELED` | `UNKNOWN` |
| --- | --- | --- | --- | --- | --- |
| 홈·개인화 추천 | 가능 | 선택 날짜와 공식 일정에 따라 가능 | 제외 | 제외 | 제외 |
| 조건 기반 추천 | 선택 날짜에 관람 가능할 때 가능 | 선택 날짜에 시작했을 때 가능 | 제외 | 제외 | 제외 |
| 검색·아카이브 | 가능 | 가능 | 가능 | 공식 취소 근거와 함께 아카이브 가능 | 최소 품질 불합격으로 사용자 검색 제외 |
| 상세 | 가능 | 가능 | 과거 정보 경고와 함께 가능 | 취소 상태와 공식 근거를 강하게 표시 | 일반 사용자 상세 제외, 운영 검토만 허용 |
| 관심·비교 | 가능 | 가능 | 가능 | 추천 후보가 아닌 참고 대상으로 제한 가능 | 제외 |

종료 전시 조회 자체는 취향 신호가 아니다. 종료 전시에 사용자가 직접 하트를 표시한 경우에만 다른 하트와 같은 긍정 신호가 된다.

검색어 없이 전시를 탐색하면 `CURRENT`와 `UPCOMING`만 기본 후보로 삼고, `현재 관람 가능 → 사용자 조건·취향 적합 → 종료 임박 → 예정 시작 임박 → 데이터 품질·정보 완성도` 순으로 우선한다. 뒤 기준은 앞 기준을 뒤집지 않는 범위에서 적용하며, 선택한 날짜·필수조건을 통과한 후보만 정렬한다. `ENDED`는 사용자가 상태 필터로 직접 선택할 때만 포함한다.

검색어가 있으면 현재·예정·종료 전시를 모두 검색하되, 텍스트 관련성과 사용자의 명시 필터가 우선이다. `CURRENT`·`UPCOMING` 우선은 관련도가 비슷한 결과 안에서 적용하며, 더 낮은 관련도의 현재 전시가 더 높은 관련도의 종료 전시를 자동으로 앞서지 않는다.

## 7. 날짜와 관람 가능성

### RULE-DATE-001 — 하루 검색

선택일이 전시 시작일과 종료일에 포함되고, 확인된 휴관·취소와 충돌하지 않을 때 날짜 조건을 충족한다.

### RULE-DATE-002 — 기간 검색

사용자 기간과 전시 기간이 겹치고, 그 안에 확인된 휴관·취소가 아닌 관람 가능일이 하루 이상 있을 때 후보에 포함한다. 전체 기간을 충족한다고 표현하지 않고 실제 가능한 구간과 확인된 휴관일을 계산해 표시한다.

### RULE-DATE-003 — 휴관

공식 휴관일이 확인되면 가능한 날짜 계산에 반영한다. 개관 여부가 미확인인 날을 임의로 관람 가능으로 확정하지 않는다.

### RULE-DATE-004 — 회차·잔여석

전시 기간 일치는 특정 회차 예약 가능 또는 잔여석을 의미하지 않는다. 미감은 실시간 회차·매진을 판정하지 않는다.

### RULE-DATE-005 — 사용자 입력 단위

사용자는 정확한 하루 또는 시작일·종료일을 직접 지정한다. `오늘`, `이번 주말`, `다음 주`처럼 시스템이 날짜 범위를 대신 정하는 빠른 기간 프리셋은 P0에서 제공하지 않는다.

## 8. Hard Filter와 Preference

### Hard Filter

- 지역
- 하루 또는 기간
- 사용자가 명시한 일반 성인 1인 최대 예산
- 반드시 필요한 접근성
- 반드시 피해야 할 감각 조건
- 사용자가 필수로 지정한 예약 조건과 예상 관람시간
- 공식 연령 제한과 실제 동행 구성의 충돌

Hard Filter를 위반한 전시는 추천하지 않는다. 시스템은 결과 수를 늘리기 위해 조건을 몰래 바꾸지 않는다.

### Preference

- 분위기
- 관심 매체
- 관계 유형
- 선호로 지정한 예상 관람시간
- 선호로 지정한 예약
- 공간 유형과 행사 형식 선호
- 관심 기관

Preference 불일치는 제외가 아니라 정렬과 추천 이유에 영향을 준다. 선택하지 않은 Preference는 비선호가 아니다.

## 9. 미확인 정보 처리

### RULE-UNKNOWN-001 — 접근성·감각 안전

확인되지 않은 접근성·감각 값은 `UNKNOWN`으로 관리한다. 필수 접근성 또는 반드시 피할 감각 조건이 `UNKNOWN`이면 충족을 증명할 수 없으므로 주요 추천에서 제외한다. 이를 기능 미지원이나 위험 존재로 단정하지 않는다.

### RULE-UNKNOWN-002 — 요금·예약·관람시간

확인되지 않은 요금·예약·관람시간은 `UNKNOWN`으로 관리하고 추론하지 않는다. 기본적으로 조건 확인 완료 후보와 섞지 않고 `추가 확인 필요`로 분리할 수 있으며 공식 링크와 마지막 확인 시각을 제공한다. 요청 계약에서 이 값이 필수 방문 조건이면 `UNKNOWN`은 조건을 충족하지 않는다.

### RULE-UNKNOWN-003 — 선호 정보

매체·주제·분위기·감상 방식·공간 유형·행사 형식의 미확인은 중립이다. 가점도 감점도 주지 않는다. 행사 형식 미확인은 선택된 형식과의 일치로 만들지 않는다.

### RULE-UNKNOWN-004 — 0건 완화

0건일 때 Hard Filter는 유지한다. 사용자가 직접 선택할 수 있는 Preference 완화만 제안하고, 접근성·감각 안전은 제안 대상에서도 제외한다. 예산은 사용자가 직접 선택할 때만 해제한다.

## 10. 동행자 규칙

관계 유형과 실제 동행 구성을 분리한다.

- `혼자`, `연인`, `친구`, `가족`, `기타`는 약한 맥락 신호다.
- 어린이·청소년·고령자·휠체어 이용자·기타 접근성 지원 필요 여부는 객관적 관람 조건이다.
- `연인에게 완벽함`, `가족이면 반드시 좋아함`, `고령자에게 적합함`처럼 관계나 집단을 근거 없이 일반화하지 않는다.

## 11. 가격 규칙

### 11.1 추천·필터 기준

일반 성인 1인의 공식 기본 관람권 하나만 사용한다. 동행자 수와 우대 조건을 이용한 총액을 계산하지 않는다.

### 11.2 상세 표시

성인·청소년·어린이·고령자·장애인 등 공식적으로 확인된 주요 가격과 할인 조건을 구조화할 수 있다. 얼리버드·패키지·도슨트·체험·특별 프로그램 가격은 기본 관람권과 분리한다.

### 11.3 가격 범위

공식 가격이 `15,000원~25,000원`처럼 제공되더라도 일반 성인 기본권을 식별할 수 없으면 최저가를 대표 가격으로 사용하지 않는다.

### 11.4 무료 전시

전시 입장이 무료이고 선택 프로그램만 유료이면 전시 자체는 무료로 판정하고 프로그램 비용을 분리한다.

### 11.5 가격 미확인

일반 성인 기본 관람권을 공식 근거로 확인할 수 없으면 가격 상태를 `UNKNOWN`으로 두고 예산 충족값을 만들지 않는다. 최대 예산이 필수 조건인 요청에서는 `UNKNOWN`이 상한 이하라는 뜻이 아니며, 조건 통과 후보로 계산하지 않는다.

## 12. 예약 규칙

예약은 다음 의미를 구분한다.

| 값 | 의미 |
| --- | --- |
| `NOT_REQUIRED` | 예약 불필요 |
| `REQUIRED` | 사전 예약 필수 |
| `RECOMMENDED` | 사전 예약 권장 |
| `TIMED_ENTRY` | 회차별 예약 |
| `ON_SITE` | 현장 접수 |
| `FIRST_COME` | 현장 선착순 |
| `PROGRAM_ONLY` | 일부 프로그램만 별도 예약 |
| `UNKNOWN` | 확인 필요 |

예약 유형은 공식 링크와 연결할 수 있지만 `예약 가능`, `매진`, `잔여 회차`를 의미하지 않는다.

## 13. 예상 관람시간

| 값 | 의미 |
| --- | --- |
| `OFFICIAL` | 기관이 직접 안내한 권장·예상 관람시간 |
| `UNKNOWN` | 신뢰할 근거 부족 |

공식 예상 관람시간이 없으면 작품 수, 영상 러닝타임, 공간 규모, 유사 전시 또는 평균값으로 시간을 계산하지 않고 `UNKNOWN`으로 둔다.

## 14. 공간 유형과 행사 형식

장소 성격과 행사 구성은 서로 다른 축이다.

### 공간 유형

- 미술관
- 박물관
- 갤러리
- 문화재단·공공문화공간
- 대안·비영리 예술공간
- 복합문화공간
- 전시 전문 상업공간
- 기타 공식 전시장

### 행사 형식

- 개인전
- 단체전
- 기획전·특별전
- 상설전
- 아트페어
- 비엔날레·트리엔날레
- 몰입형·체험형 전시
- 브랜드 문화전시
- 축제 연계 전시
- `UNKNOWN` (`형식 미확인`)

`UNKNOWN`은 행사 형식의 공식 근거가 없어 값을 부여하지 못한 상태다. 제목, 공간 유형, 매체, 분위기 또는 유사 전시를 근거로 개인전·기획전 등을 추정하지 않으며, 형식 필터에서 일치하는 값으로 취급하지 않는다.

## 15. 매체 체계

사용자 입력은 쉬운 상위 그룹과 세부 매체를 분리한다. 하나의 전시·작품은 여러 매체를 동시에 가질 수 있다.

| 상위 그룹 | 세부 매체 예시 |
| --- | --- |
| 그림과 평면 작품 | 회화, 드로잉, 판화, 서예 |
| 사진 | 사진 |
| 입체와 공간 | 조각, 설치, 건축·공간 |
| 공예와 디자인 | 도자, 공예, 패션, 제품·시각디자인 |
| 영상과 디지털 | 영상, 애니메이션, 미디어아트, 디지털아트 |
| 소리와 공연 | 사운드 아트, 퍼포먼스, 라이브 미디어 |
| 직접 참여하는 작품 | 인터랙티브, 체험형 설치, 관객 참여형 퍼포먼스 |

상위 그룹을 선택하지 않았다고 해당 매체를 싫어한다고 해석하지 않는다.

## 16. 주제와 분위기

### 주제

P0 주제 대분류는 다음 범위 안에서 관리한다.

- 자연·생태·환경
- 도시·공간·건축
- 기술·디지털
- 기억·시간
- 역사·전통
- 사회·정치
- 정체성
- 몸·감각
- 일상
- 관계·공동체
- 젠더
- 노동
- 미래·상상
- 예술·창작 자체
- 기타

공식 태그를 우선하고, 공식 제목·소개문의 명시적 표현을 규칙 기반으로 연결한다. 불충분하면 태그를 만들지 않는다.

### 분위기

사용자-facing 분위기는 차분한·몰입형·활기찬·사유형·참여형·실험적이다. 각 분위기는 다음 근거 상태를 가져야 한다.

| 근거 | 의미 |
| --- | --- |
| `DIRECT` | 공식 설명·분류에 직접 표현됨 |
| `DERIVED` | 승인된 객관 조건 조합으로 파생됨 |
| `UNKNOWN` | 충분한 근거가 없어 태그를 붙이지 않음 |

`영상이 있음`만으로 몰입형, `회화 전시`만으로 차분한이라고 분류하지 않는다. 참여형은 관람객 조작·센서 반응·참여 퍼포먼스처럼 확인 가능한 경험 근거가 필요하다.

## 17. 접근성·감각 정보

### 접근성

- 엘리베이터 등 이동 정보
- 자막
- 수어
- 오디오 설명
- 어린이·연령 조건

### 감각 주의

- 큰 소리
- 갑작스러운 소리

각 항목은 긍정·부정·미확인을 구분해야 한다. 미확인은 `지원 안 함`, `자극 없음`과 같지 않다.

## 18. 전시·작품·기관 관계

### RULE-REL-001

기관이 작품을 소장한다는 사실은 현재 전시를 뜻하지 않는다.

### RULE-REL-002

작가가 전시에 참여한다는 사실만으로 그 작가의 특정 작품이 출품되었다고 표시하지 않는다.

### RULE-REL-003

전시와 작품의 연결은 공식 출품 목록 또는 동등한 공식 근거가 있을 때만 생성한다.

### RULE-REL-004

제목이 같은 순회전·재개최·재공연은 장소·기간·요금·예약 조건이 다르면 별도 전시로 유지한다. 공식적으로 확인된 경우에만 같은 시리즈 관계를 둘 수 있다.

## 19. 관심과 취향 신호

### RULE-PREF-001

취향 테스트의 긍정 선택과 전시·작품·기관 하트만 장기 취향의 명시적 신호다.

### RULE-PREF-002

하트는 저장과 긍정 신호를 겸하며, 해제는 긍정 신호 제거다. 비선호로 변환하지 않는다.

### RULE-PREF-003

노출, 상세 조회, 검색, 비교, 공식 링크 클릭, 스크롤, 체류시간, 최근 본 기록은 취향 신호가 아니다.

### RULE-PREF-004

기관 하트는 해당 기관의 현재·예정 전시를 약하게 우선할 수 있지만 기관의 모든 매체·전시·소장품을 선호한다고 해석하지 않는다.

## 20. 추천 설명 불변식

1. 사용자-facing 퍼센트를 좋아할 확률처럼 표시하지 않는다.
2. 이유는 실제 점수에 기여한 테스트·하트·전시 특성에서만 생성한다.
3. 카드에는 가장 강한 이유 하나, 상세에는 존재하는 범위에서 최대 3개를 제공할 수 있다.
4. 이유가 부족하면 문장 수를 맞추기 위해 근거를 생성하지 않는다.
5. 탐색형 추천은 무작위가 아니라 기존 취향과 적어도 한 축의 연결점이 있어야 한다.
