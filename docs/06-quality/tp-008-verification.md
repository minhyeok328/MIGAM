작품 API의 미승인 Source 차단, 숨김 이미지 URL·추정 출품 관계 거부, 기존 로컬 v1 데이터 보존, 작품 관심의 현재 특성만 추천에 사용, 검색어 비영속을 검증했다. 상세·관심·비교·전체 초기화, 취향 저장·건너뛰기·추천과 삭제창 ESC 포커스 복귀를 컴포넌트 통합 테스트로 연결했다.

브라우저 검증 중 단일 스레드 데모 서버가 빈 사전 연결을 기다리며 다음 요청을 막는 문제를 발견했다. 빈 TCP 연결이 열린 상태에서 후속 요청이 시간 초과되는 테스트를 먼저 확인하고, 요청별 스레드·10초 대기 제한·스레드별 DB 연결 종료를 적용한 뒤 통과했다. 정상 종료 시 임시 DB 정리와 기존 DB 바이트 보존도 자동 검증한다. 이 서버는 계속 loopback 데모 전용이다.

## 실제 브라우저 확인

Codex In-app Chromium과 실제 Django API를 사용했다. 테스트 값을 사용자 실데이터 저장소에 넣지 않도록 관심·초기화 검증은 5181 격리 가상 데모에서 수행했다.

- 실제 5173: 유영국 전시 상세, 공식 링크, UNKNOWN 방문 정보, 외부 카카오맵 링크 확인. 연결 오류 후 재시도로 회복. 긴 제목의 데스크톱·390px 줄바꿈과 가로 넘침 없음 확인.
- 실제 작품 목록: `SOURCE_PENDING` 안내와 가상 작품 미노출 확인.
- 가상 작품: 목록 4개 → 상세 → 관심 저장 → 새로고침 후 관심 유지 → 작품 특성이 반영된 추천 6개 확인. 유사 작품의 제작자·소장기관 근거와 미확인 출품 관계 표시 확인.
- 가상 전시: 추천 → 상세 → 관심과 비교 → 전시 3개 추가, 네 번째 추가 제한 → 모바일 비교 화면 확인.
- 취향: 회화 선택 → 다음 → 건너뛰기 → 저장 → 결과 → 추천 이동 확인.
- 내 데이터: 삭제 확인창 취소/ESC 시 호출 버튼으로 포커스 복귀, 전체 삭제 후 취향·전시·작품·기관·최근 기록과 비교 모두 0 확인.
- 390×844에서 전시 상세·비교·취향·삭제창을 시각 점검했다. 비교·삭제창·실제 상세의 가로 넘침이 없었다. 브라우저 콘솔에서 가상 작품 검증 중 오류 0건이었다.

브라우저 조작 검증은 재현 가능한 CI 브라우저 테스트 스크립트를 대신하지 않는다. 200% 확대, 실제 모바일, 스크린리더, Firefox/WebKit, Docker 컨테이너는 이번 실행에서 확인하지 않았다.
