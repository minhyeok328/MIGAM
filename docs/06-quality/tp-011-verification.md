# TP-011 실제 전시 콘텐츠 검증 기록

## 반영 범위

2026-09-07 현재 검색 결과 17건 모두 공식 상세 페이지를 검토해 소개·볼거리·세부 장소를 실제 DB에 반영했다. 요금 및 운영시간 문구는 각각 14건, 연령 안내는 1건이다. 자료는 [검토 JSON](../../data/reviewed/exhibition-content-2026-09-07.json)에 공식 URL·책임 기관·검토 시각·짧은 근거 메모와 함께 보존했다. 공식 본문을 그대로 복제하거나 이미지를 수집하지 않았다.

- ID `1`: 세종문화회관 이수경 개인전.
- ID `6, 7, 11, 319, 320, 321, 322, 323, 324, 326, 330, 331, 344`: 서울시립미술관 13건.
- ID `16, 17`: 수원시립미술관 2건. 공식 상세의 가격은 별도 관람안내 참조이므로 금액·운영시간을 추정하지 않았다.
- ID `21`: 국립민속박물관 기획전. 해당 상세에 없는 가격·운영시간은 채우지 않았다.

예시로 [서서울미술관 플레이 라운지 공식 안내](https://sema.seoul.go.kr/kr/whatson/exhibition/detail?exNo=1576627)의 작가·영상 구성·요금·공간·운영 안내를 검토했다. 상세 페이지는 소개·볼거리·확인한 안내를 직접 보여주고 미확인 행을 반복하지 않는다. 기존 방문 정보의 충돌은 검토 문구로 덮지 않는다. 자기 자신으로 연결되는 목록 카드와 중복 제목을 제거했다.

## 데이터 보존과 API

- 변경 전 SQLite backup: `data/incoming/backups/db-content-20260907T080720Z-5b697fcf.sqlite3`. backup과 반영 후 DB의 무결성 검사 결과 모두 `ok`.
- migration `catalog.0008_exhibition_content` 적용, import 결과 `created=17 unchanged=0`.
- 전시 758건·SourceRecord 965건을 포함한 기존 업무 테이블 37개의 행 수·전체 행 hash를 백업과 비교해 변경 0건을 확인했다. 비교 기록: `data/incoming/tp-011-preservation.json`. 신규 콘텐츠 17건과 migration 이력만 추가했다.
- 실제 검색 API의 17개 ID 각각을 상세 조회해 모두 `content != null`임을 확인했다. 5173 프록시에서도 ID 6의 소개·무료·시간·장소 응답을 확인했다.
- OpenAPI `1.6.0`과 생성 TypeScript·Zod가 일치한다. 콘텐츠 문구는 기존 가격·예약·운영일의 확정 상태와 추천 후보 판정을 바꾸지 않는다.

## 검증

- Django 전체 **303개 통과**. 입력의 전시·원본 hash 불일치, 미등록 연결, 미래 날짜·30일 초과 만료, HTML·중복 키/안내, 전체 검증 후 원자적 반영, 멱등성, 원본 교체·정본 변경·만료 시 제외, 불변 이력을 포함한다.
- 프론트 **13개 파일 83개 테스트 통과**. 실제 내용 표시, 내용 없음, 미확인 행 생략, 단일 공식 링크, 충돌 유지, 가상 모드와 잘못된 콘텐츠 응답을 확인했다.
- Chromium·390px Chromium·WebKit 및 공식 안내 계약의 **브라우저 24개 테스트 통과**. 새 콘텐츠 표시와 외부 링크의 새 창·referrer 차단, 기존 관심·비교·초기화·검색·추천·취향 흐름을 포함한다.
- TypeScript/build 및 API 생성 일치 검사, 프론트 Prettier 검사 통과. 최종 CSS는 빌드와 브라우저 회귀에 반영했다.
- 실제 ID 6을 데스크톱·390px에서 시각 점검했다. 모바일 문서 폭과 뷰포트 모두 390px이며 소개·볼거리·관람 안내에 가로 넘침이 없다. 임시 뷰포트 설정을 복원했다.

## 한계와 갱신

현재 노출 17건을 대상으로 한 수동 검토다. 나머지 741건의 소개, 별도 관람안내에서 가져올 3건의 요금·시간, 예약·접근성 전체 확보는 이번 완료 범위가 아니다. 2026-09-07 16:58 KST 검토 자료는 2026-10-07 16:58 KST까지 유효하다. 원본·정본 식별 변경이나 만료 후에는 공식 페이지를 다시 검토해 새 스냅샷으로 추가해야 하며 날짜만 바꿔 확인을 연장하지 않는다. API 핵심 확인 시각과 수집 성공 이력은 별도로 유지된다.

Firefox의 기존 Windows 실행 환경 오류는 TP-010에 기록된 상태이며 이번에 재실행하지 않았다. 원격 CI 실행·공개 배포·커밋·푸시는 하지 않았다.
