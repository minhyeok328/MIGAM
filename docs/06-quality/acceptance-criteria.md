# 미감 P0 합격 기준

## 1. 판정 원칙

P0는 기능이 화면에 존재하는지만으로 합격하지 않는다. 대표 데이터에서 `발견 → 이해 → 판단` 흐름을 완수하고, 데이터·추천·권리·접근성 불변식을 함께 만족해야 한다.

- 각 `AC-###`의 조건을 모두 충족해야 해당 항목이 통과한다.
- 자동 검증과 수동 검증이 함께 지정된 항목은 둘 다 통과해야 한다.
- 외부 출처나 지도 제공자의 실패는 정상적인 저하 시나리오로 검증한다.
- 아직 코드가 없으므로 이 문서는 실행 명령을 선언하지 않는다. 실제 명령은 구현된 매니페스트와 검증 설정에서 확인한 뒤 문서 버전을 올려 기록한다.
- 아래 요구사항 ID는 `prd-p0.md`의 실제 `P0-FR-*`, `P0-NFR-*`, `P0-OUT-*`를 사용한다.

## 2. 무관용 불변식

다음 위반은 허용 건수가 0건이다. 하나라도 재현되면 관련 기능과 P0 전체 판정을 통과시킬 수 없다.

| 불변식 | 근거 요구사항 |
| --- | --- |
| 사용자가 정한 하드 필터를 위반한 일반 추천 | `P0-FR-032`~`P0-FR-035` |
| 종료·취소 전시가 현재·예정 전시 추천으로 노출 | `P0-FR-026`, `P0-FR-040`, `P0-FR-059` |
| `UNVERIFIED` 전시가 홈·일반 추천으로 노출 | `P0-NFR-008` |
| 동일 전시가 같은 결과나 추가 로딩 묶음에 중복 노출 | `P0-FR-045`, `P0-FR-051` |
| 추천 이유가 실제 취향 신호·전시 특성과 불일치 | `P0-FR-050`, `P0-FR-052` |
| `LINK_ONLY`·`RIGHTS_UNKNOWN` 이미지가 화면에 표시되거나 핫링크 요청됨 | `P0-FR-015`, `P0-NFR-007`, `P0-OUT-008` |
| 미확인 요금·예약·접근성·감각 정보를 확인된 사실로 표시 | `P0-FR-035`~`P0-FR-037`, `P0-FR-054`~`P0-FR-057` |
| 조회·검색·비교·최근 본 기록을 취향 신호로 반영 | `P0-FR-004`, `P0-FR-071`, `P0-OUT-002` |

## 3. 발견 단계

### `AC-001` 계정 없는 두 진입 경로

**추적 요구사항:** `P0-FR-001`, `P0-FR-006`

- 새 브라우저 상태의 사용자가 계정 생성·로그인·서버 익명 프로필 없이 홈을 사용할 수 있다.
- `내 취향부터 알아보기`와 `지금 갈 전시 찾기`가 같은 화면에서 같은 위계의 주요 행동으로 제공된다.
- 어느 경로를 선택해도 현재·예정 전시 후보까지 도달할 수 있다.
- 한 경로를 완료하지 않아도 다른 경로와 통합검색을 사용할 수 있다.

### `AC-002` 적응형 취향 테스트

**추적 요구사항:** `P0-FR-012`~`P0-FR-017`

- 기본 단계는 약 8문항으로 시작하며 추가 문항은 응답에 필요한 축에서만 나오고 최대 4~6문항 범위를 넘지 않는다.
- 복수 카드 선택, 상황 비교, 매체 복수 선택을 대표 시나리오에서 각각 수행할 수 있다.
- `둘 다 좋아요`, `잘 모르겠어요`, `건너뛰기`, 기본 단계 이후 `결과 보기`가 동작한다.
- 미선택·유보·건너뛰기 값은 부정 신호를 만들지 않는다.
- 시각 문항은 재사용 권리 확인 이미지만 사용하고 이미지가 없는 자료는 시각 선택 문항에서 제외한다.
- 음원·전체 영상을 다운로드·재호스팅·자동 재생하지 않아도 테스트를 완료할 수 있다.

### `AC-003` 취향 결과와 재테스트

**추적 요구사항:** `P0-FR-018`~`P0-FR-021`

- 결과는 퍼센트가 아닌 정성적 요약으로 표시되고 각 요약에서 테스트 또는 관심 근거를 확인할 수 있다.
- 탐색이 적은 축을 비선호로 표시하지 않는다.
- 지역·날짜가 없으면 현재·예정 전시 후보를 보여주되 방문 조건을 반영한 추천이 아님을 명시한다.
- 재테스트 후 최신 테스트 결과가 이전 결과를 대체하고, 사용자가 유지한 관심 신호는 남는다.

### `AC-004` 지금 갈 전시 입력

**추적 요구사항:** `P0-FR-022`~`P0-FR-031`

- 지역과 하루 또는 직접 지정 기간을 필수로 받아 조건 검색을 시작한다.
- 지역은 시·도 및 시·군·구 수동 선택으로 완결되며 현재 위치 버튼을 누르기 전에는 위치 권한을 요청하지 않는다.
- 위치 거절·실패 후 수동 지역 선택으로 동일 과업을 완료한다.
- 선택 기간 안에 확인된 휴관·취소가 아닌 관람 가능일이 하루 이상 있어야 후보가 되며, 일부만 가능하면 실제 구간과 휴관일을 구분한다.
- 최대 예산은 일반 성인 1인 기본 관람권을 사용하며 임의 최저가·할인가로 통과시키지 않는다.
- 동행·분위기·매체·관람시간·예약·행사 형식은 선택적으로 입력할 수 있고 미선택을 비선호로 해석하지 않는다.

### `AC-005` 필수 조건과 미확인 정보

**추적 요구사항:** `P0-FR-032`~`P0-FR-037`

- 알려진 위반값을 가진 전시는 지역·날짜·최대 예산·필수 접근성·회피 감각 조건의 일반 추천에서 제외된다.
- 필수 접근성·감각 정보가 미확인이면 조건 충족으로 간주하지 않고 해당 필수조건 추천에서 제외한다.
- 요금·예약·관람시간 미확인 전시는 충족 후보와 같은 정상 추천처럼 섞지 않고 `추가 확인 필요`로 구분한다.
- 매체·분위기 같은 선호 정보 미확인은 가점·감점 없이 중립으로 처리한다.
- UI와 추천 요청을 반복해도 시스템이 하드 필터를 자동 변경하지 않는다.

### `AC-006` 0건 결과의 사용자 주도 회복

**추적 요구사항:** `P0-FR-046`, `P0-FR-034`

- 0건 화면에서 현재 검색어와 조건을 확인할 수 있다.
- 분위기·매체 등 선호 조건의 조정안을 제안할 수 있으나 적용은 사용자가 선택한 뒤에만 일어난다.
- 예산 해제는 사용자가 직접 선택한 경우에만 적용된다.
- 지역·날짜·필수 접근성·회피 감각 조건은 자동 완화와 완화 제안 모두에서 유지된다.
- 조정 후 변경된 조건이 필터 칩과 URL에 즉시 반영된다.

### `AC-007` 탐색·통합검색·추가 로딩

**추적 요구사항:** `P0-FR-038`~`P0-FR-045`

- 통합 검색에서 전체, 전시, 작품·소장품, 기관 탭을 전환하고 각 유형 상세로 이동한다.
- 검색어 없는 전시 탐색은 현재·예정이 기본이며 종료는 상태를 직접 선택해야 나타난다.
- 키워드 검색은 종료 전시도 찾되 현재·예정·종료 상태를 명확히 구분하고 관련도를 개인화보다 우선한다.
- 독립 작가 탭 없이 작가명으로 전시·작품을 찾을 수 있다.
- 최초 24개, 더 보기마다 다음 24개, 총 결과 수가 일치하고 중복 항목이 없다.
- 필터 변경 시 누적 목록이 초기화되고 검색어·필터·정렬은 URL과 새로고침에서 복원된다.
- 상세에서 뒤로 이동하면 가능한 범위에서 이미 불러온 목록과 위치가 복원된다.

## 4. 이해 단계

### `AC-008` 설명 가능한 추천과 다양성

**추적 요구사항:** `P0-FR-007`~`P0-FR-011`, `P0-FR-047`~`P0-FR-052`

- 취향 신호가 없는 사용자는 현재·예정, 최신성, 정보 품질, 기관·매체 다양성에 기반한 후보를 받는다.
- 적은 신호는 약하게, 최신 테스트와 관심 신호가 쌓인 경우 더 강하게 반영되며 하나의 관심만으로 추천이 한 유형에 고정되지 않는다.
- 홈 대표 추천은 기본 6개이며 고정 데이터 시나리오에서 같은 기관·매체의 과도한 반복을 방지한다.
- 후보가 충분한 시나리오에서는 약 6개 중 1개가 기존 취향과 최소 한 축이 연결된 탐색형 이유를 가진다.
- 사용자 화면에 내부 점수 퍼센트를 노출하지 않는다.
- 카드는 가장 강한 실제 이유 1개, 상세는 존재하는 실제 이유를 최대 3개까지만 보여준다.

### `AC-009` 전시 상세의 방문 판단 정보

**추적 요구사항:** `P0-FR-053`~`P0-FR-060`

- 상태, 이름, 기간, 장소, 매체, 추천 이유, 출처와 마지막 확인 시점을 확인한다.
- 공식 소개와 구조화 요약이 구분되고 데이터에 없는 의도·해설을 만들지 않는다.
- 상세 가격표는 공식 확인된 주요 가격을 구조화하며 기본권·할인·얼리버드·패키지·프로그램 요금을 구분한다.
- 예약 방식을 구분하고 공식 링크를 제공하되 잔여석·매진과 동행자 예상 총액을 판단하지 않는다.
- 관람시간의 공식값·근거 있는 추정 범위·미확인을 구분한다.
- 공식 연결이 확인된 작품만 출품작으로 표시한다.
- 종료 전시는 현재 관람 불가와 과거 정보 경고를 상단부터 보여주고 비슷한 현재·예정 전시로 연결한다.

### `AC-010` 작품·기관 상세의 근거 보존

**추적 요구사항:** `P0-FR-061`~`P0-FR-065`

- 작품 상세는 작품명, 작가, 시대·제작연도, 매체·재질, 문화권, 소장기관, 출처·권리를 제공한다.
- P0 유사 작품은 메타데이터 일치 이유를 제시하며 이미지 임베딩 결과를 사용하지 않는다.
- 같은 작가·기관과 공식 전시 출품 연결을 서로 다른 관계로 표시한다.
- 기관 상세는 방문 정보와 현재·예정·과거 전시를 구분한다.
- 기관 성격은 등록 전시 집계로만 설명하며 근거 없는 `데이트하기 좋은`, `실험적인` 평가를 만들지 않는다.

## 5. 판단 단계

### `AC-011` 관심과 최근 본 전시

**추적 요구사항:** `P0-FR-066`~`P0-FR-071`

- 전시·작품·기관에 같은 `관심 있음` 행동을 제공하고 새로고침 뒤에도 현재 브라우저에서 유지한다.
- 관심 해제는 저장과 긍정 신호를 제거하지만 부정 신호를 만들지 않는다.
- 관심 전시와 기관은 현재 상태에 맞는 시스템 그룹으로 자동 이동하며 종료 후에도 관심이 유지된다.
- 사용자 지정 폴더·메모·공유·직접 정렬을 제공하지 않는다.
- 최근 본 기록은 전시만 최대 10~20개를 유지하고 중복 행을 만들지 않으며 추천 점수에 영향을 주지 않는다.

### `AC-012` 최대 3개 전시 비교

**추적 요구사항:** `P0-FR-072`~`P0-FR-074`

- 상태와 관계없이 전시 1~3개를 비교할 수 있다.
- 네 번째 추가 시 기존 항목을 자동 교체하지 않고 제한과 제거 방법을 안내한다.
- 데스크톱은 열 비교표, 모바일은 속성별 세로 비교로 같은 핵심 값을 제공한다.
- `확인되지 않음`과 `조건 불충족`이 다른 텍스트 상태로 읽힌다.
- 종료 전시에는 현재 관람 불가와 과거 정보 경고가 고정 표시된다.
- 비교 결과가 자동 순위·방문 순서·일정으로 변환되지 않는다.

### `AC-013` 선택형 지도와 위치

**추적 요구사항:** `P0-FR-075`~`P0-FR-079`, `P0-FR-024`

- 전시 탐색은 목록으로 시작하고 사용자가 `지도에서 보기`를 선택해야 지도를 연다.
- 목록과 지도는 같은 필터와 결과 집합을 사용하고 지도에 별도 필터가 없다.
- 핀에서 기관, 포함 전시, 현재·예정 상태, 상세·관심 행동을 확인할 수 있다.
- 위치는 사용자 요청 후 현재 검색에만 사용되며 저장 데이터와 장기 로그에 남지 않는다.
- 지도·위치 실패 후 목록과 수동 지역 선택으로 과업을 완료한다.
- 경로·이동시간·교통·식당·카페 기능이 없다.

### `AC-014` 로컬 저장·부분 초기화·개인정보 안내

**추적 요구사항:** `P0-FR-002`~`P0-FR-005`, `P0-FR-080`~`P0-FR-084`

- 취향, 관심, 최근 본 전시가 현재 브라우저에서 재접속 후 유지되고 서버 사용자 프로필은 생성되지 않는다.
- 손상되거나 읽을 수 없는 저장 버전이 있어도 서비스 전체가 중단되지 않고 안전한 초기 상태로 회복한다.
- 취향 테스트 다시 하기, 관심 목록 초기화, 취향 데이터 초기화, 모든 로컬 데이터 삭제가 문서화된 삭제·유지 범위대로 각각 동작한다.
- 전체 삭제는 삭제 범위와 복구 불가를 알리는 확인을 거치며 취소 시 값이 유지된다.
- 저장 위치와 위치정보 사용 방식을 설정 또는 푸터에서 확인한다.
- 외부 행동 분석 전송과 추적 동의 배너가 없으며 검색어 원문·정확 좌표·취향 payload를 장기 로그에 남기지 않는다.

## 6. 데이터·권리·회복성

### `AC-015` 이미지 권리와 화면 대체

**추적 요구사항:** `P0-FR-015`, `P0-NFR-007`, `P0-OUT-008`

- `REUSE_ALLOWED` 이미지만 카드·상세·취향 테스트에서 표시한다.
- `LINK_ONLY`와 `RIGHTS_UNKNOWN` URL로 브라우저 이미지 요청을 보내지 않는다.
- 이미지가 없거나 실패해도 텍스트형 카드에서 상태·기간·기관·추천 이유와 상세·관심·비교 행동을 동일하게 제공한다.
- 포스터 권리와 개별 작품 권리를 독립적으로 판정한다.

### `AC-016` 최신성·충돌·기능 저하

**추적 요구사항:** `P0-NFR-006`, `P0-NFR-008`, `P0-NFR-009`, `P0-FR-059`

- 수집 실패만으로 마지막 검증 데이터를 삭제하거나 실패값으로 덮어쓰지 않는다.
- `STALE`은 검색에 남되 경고·마지막 확인 시점·공식 링크를 제공하고 추천 우선순위를 낮춘다.
- `UNVERIFIED`는 홈·일반 추천에서 제외하고 검색의 추가 확인 영역에서만 경고와 함께 나타난다.
- 종료 전시는 아카이브에 남지만 현재 추천에 나타나지 않는다.
- 방문 핵심값이 충돌하면 해당 값을 사실로 확정하지 않고 추천에서 제한한다.
- 데이터가 적은 지역은 결과 수와 커버리지 제한을 숨기지 않는다.

### `AC-017` 데이터 정규화·중복·출처 품질

**추적 요구사항:** `P0-FR-086`, `P0-NFR-006`, `P0-NFR-008`

- 대표 픽스처에서 날짜·주소·지역·요금·매체·상태 정규화 결과가 기대값과 일치한다.
- 공식 동일 ID 또는 강한 제목·기관·기간 근거가 있는 항목만 자동 병합되고 모호한 항목은 중복 후보로 남는다.
- 순회전은 장소·기간별 별도 전시를 유지하고 시리즈 관계만 연결한다.
- 필드별 출처 우선순위, 원본값, 표시값, 확인 시점과 충돌 상태를 역추적할 수 있다.
- 전시 상태와 `FRESH`·`STALE`·`UNVERIFIED` 판정이 경계 날짜와 수집 실패 시나리오에서 일관된다.
- 권리 미확인 미디어가 사용자 노출 가능 상태로 변환되지 않는다.

### `AC-018` API·프론트 경계와 저장소 회복

**추적 요구사항:** `P0-FR-005`, `P0-FR-044`, `P0-FR-045`, `P0-FR-080`~`P0-FR-083`

- 검색·추천·상태 응답이 OpenAPI 계약과 일치하고 프론트 경계 검증 실패를 정상 데이터처럼 렌더링하지 않는다.
- 필터·정렬·페이지 상태가 URL 및 화면 상태와 일치한다.
- 관심·취향·최근 본 전시 저장소는 컴포넌트 직접 접근 없이 버전과 마이그레이션·손상 복구를 검증할 수 있다.
- 카드, 필터, 관심, 비교, 대화상자, 바텀시트의 로딩·빈·오류·선택 상태가 컴포넌트 수준에서 재현된다.

## 7. 전체 흐름·접근성·호환성

### `AC-019` 대표 E2E 흐름

**추적 요구사항:** `P0-FR-006`, `P0-FR-012`, `P0-FR-022`, `P0-FR-038`, `P0-FR-066`, `P0-FR-072`, `P0-FR-075`, `P0-FR-080`, `P0-NFR-007`

다음 12개 흐름이 대표 데모 데이터에서 반복 통과한다.

1. 홈 → 취향 테스트 → 추천 결과
2. 지금 갈 전시 찾기 → 조건 입력 → 추천
3. 전시 탐색 → 검색·필터 → 상세
4. 전시 2~3개 → 비교
5. 전시 관심 → 관심 목록 → 관심 해제
6. 작품 관심 → 관심 목록
7. 기관 관심 → 관심 기관
8. 검색 → 현재·예정·종료 전시 구분
9. 목록 → 지도 보기 → 목록 복귀
10. 브라우저 저장 데이터의 부분·전체 초기화
11. 새로고침 후 관심·취향 유지
12. 권리 없는 이미지 → 텍스트형 대체 카드

### `AC-020` 접근성·반응형·브라우저

**추적 요구사항:** `P0-NFR-001`~`P0-NFR-005`

- 키보드만으로 두 진입 경로, 테스트, 검색·필터, 상세, 관심, 비교, 전체 삭제를 완료한다.
- 모든 조작 요소에 보이는 포커스가 있고 대화상자·바텀시트·팝오버의 포커스 진입·순환·복귀가 올바르다.
- 하트·현재·예정·종료·오류·확인 필요를 색상이나 아이콘 없이도 텍스트로 이해한다.
- 정보 이미지의 대체 텍스트, 장식 이미지의 빈 대체 텍스트, 폼 레이블과 상태 알림이 의미에 맞는다.
- 모션 감소, 화면 확대, 터치 입력에서도 핵심 정보와 행동이 사라지거나 겹치지 않는다.
- Chromium에서 전체 E2E가, Firefox와 WebKit에서 핵심 스모크 흐름이 통과한다.
- 최신 Chrome·Edge·Firefox·Safari, Android Chrome·iOS Safari에서 핵심 과업을 완료한다.
- 자동 접근성 검사 결과와 수동 키보드·확대·스크린리더 검토에서 해결되지 않은 핵심 과업 차단 문제가 없다.

### `AC-021` 관리자 품질 영역 분리

**추적 요구사항:** `P0-FR-085`~`P0-FR-087`

- 일반 사용자는 관리자·품질 관리 화면과 운영 API에 접근할 수 없다.
- Django 관리자 인증을 거친 운영자는 전시 상태, 최신성, 출처 충돌, 중복 후보, 권리 확인 필요, 수집 성공·실패와 재확인 대상을 확인한다.
- 운영자 인증이 일반 사용자 계정·로그인 기능으로 노출되거나 재사용되지 않는다.

## 8. 명시적 비범위

### `AC-022` 폐기된 초기안과 인접 기능의 비노출

**추적 요구사항:** `P0-OUT-001`~`P0-OUT-008`

- 일반 사용자 계정·익명 서버 프로필·기기 간 동기화 경로가 없다.
- 별도 좋아요·싫어요·봤어요와 조회·클릭·체류시간 기반 취향 학습이 없다.
- 사용자 지정 컬렉션·메모·공유·커뮤니티·리뷰가 없다.
- 티켓 구매·결제·예약 대행·잔여석·매진 판정·동행자 예상 총액 계산이 없다.
- 자동 일정표·방문 순서·이동 경로·교통·식당·카페·캘린더 기능이 없다.
- 네이티브 앱·PWA·오프라인·푸시·백그라운드 위치 기능이 없다.
- 다국어 UI·작가 독립 탐색·P0 이미지 임베딩·근거 없는 LLM 해설이 없다.
- 권리 또는 접근 통제가 불명확한 미디어를 수집·표시하는 경로가 없다.

## 9. 열린 결정이 합격 판정에 미치는 영향

- `OD-003`: 실제 수도권 기관 allowlist가 확정되기 전에도 데모·계약 픽스처 기반 합격 판정은 가능하다. 실제 출처별 수집 승인과 운영 재검증 항목은 이 결정이 해소된 뒤 최종 승인할 수 있다.
- `OD-004`: 정보 위계·키보드·대비·확대 합격 기준은 현재 적용한다. 최종 워드마크와 폰트 렌더링에 대한 시각 회귀 승인은 이 결정이 해소된 뒤 수행한다.
