# TP-012 무료 공개 배포와 일일 공식 데이터 갱신

사용자는 2026-09-19 홈 미리보기를 현재 완료된 버전으로 확대하고, 비용은 무료 범위로 제한하며 처음부터 정기 수집·자동 갱신을 구성하도록 요청했다. 이 결정은 DEC-118의 공개 배포 제외 범위만 대체한다. 일반 사용자 로그인·행동 분석·새 기관·이미지·장문 원문 수집은 추가하지 않는다.

## 완료 조건

- Vercel의 동일 origin에서 홈·탐색·추천·상세·저장·비교·취향·기존 지도 기능을 제공한다.
- 영속 정본은 비공개 Blob에 보관하고 API에는 읽기 전용 SQLite 복사본만 연결한다. SQLite FTS5와 기존 품질 계약을 유지한다.
- 한국 시간 매일 06시대 예약 작업으로 승인 Source의 공식 입력을 수집하고 기존 검증·정본화·최신성·검색 투영을 실행한다. Hobby 실행 시각은 분 단위로 보장되지 않는다.
- 원본 조회 실패·권리/구조 실패를 정상 확인으로 기록하지 않는다. 마지막 정상 정본과 실패 증거를 보존한다. 날짜만 바꿔 검토 콘텐츠의 유효기간을 연장하지 않는다.
- Admin·DB 파일·수집 원문·자격 증명은 공개하지 않는다. 일반 방문자 요청은 DB를 수정하지 않는다.
- 무료 할당량 안에서만 운영한다. 유료 전환·사용량 결제·유료 도메인은 범위 밖이다.

## 구현 순서와 검증

1. 공개 settings/WSGI와 경로 분리: 허용 host, Admin 차단, 비밀값 부재 시 안전한 실패, 기존 조회·추천 API 회귀.
2. 비공개 스냅샷 저장: 무결성·크기·hash 검증, 원자 교체, 동시 갱신 충돌 방지, 장애 때 이전 정상 버전 보존. 가상 저장소로 오류·경쟁 테스트.
3. 공식 CSV 자동 획득과 일일 수집: 고정 승인 host/경로, 403·429 중단, 획득 시각·hash, 전체 CSV의 allowlist 필드만 처리. 기존 수집 게이트·공식 API 순차 호출 유지.
4. Vercel 빌드·API rewrite·Cron과 무료 저장소 연결. 로컬 DB는 읽기 백업으로만 초기화하며 원본은 변경하지 않는다.
5. 백엔드·프론트·API·격리 E2E 검사 후 공개 URL의 탐색→상세→저장/비교와 수집 결과를 실제 확인한다. 원격 실행 전에는 배포 성공·자동 수집 성공으로 표시하지 않는다.

## 보존 경계

검토 소개·볼거리의 수동 검토 계약과 최대 30일 유효기간은 유지한다. 일일 공식 기초 데이터 확인이 상세 서술의 새 검토를 의미하지 않는다. 현재 로컬 데이터·백업·환경 파일은 Git과 정적 배포물에서 제외한다.
