# TP-008 P0 제품 E2E 완성

## 승인과 완료 범위

2026-09-06 사용자의 “e2e로 너가 다 해줄 수 있어? 로그인같이 필요할때만 불러줘”를 P0 잔여 기능의 구현·수정·로컬 검증에 대한 위임으로 기록한다. 이미 확정된 제품·개인정보·출처 원칙 안의 설계 선택은 작업자가 수행한다. 원본과 기존 작업을 보존하고 main에서 작업한다. 비용·계정 로그인·새 외부 권한·최종 공개에 필요한 사용자 행동은 결과를 먼저 준비한 뒤 요청한다. 공개 운영은 OD-001·002·005·006의 결정 범위를 유지한다.

완료 기준은 키 없는 로컬 환경에서 홈 → 취향 또는 조건 선택 → 검색·추천 → 상세 → 관심·비교 → 지도/공식 안내 → 개인정보 초기화까지 연결되고, staff 데이터 운영과 재현 가능한 검증이 갖춰지는 것이다. P1·P2의 결제·공개 API·챗봇·계정·행동 분석을 추가하지 않는다. 외부 출처 미응답·사용자 로그인·실제 기기 검증 등 수행하지 못한 사항은 완료 처리하지 않는다.

## 구현 단위와 계약

1. **수집 커버리지**: 이미 받은 공식 CSV를 우선 재사용하여 추가 물리 기관 후보의 최근 5건을 항목별 심사한다. 4/5 이상의 CORE_PASS와 구조·정책 veto 통과 근거가 있는 기관만 sources.yaml에 PROVISIONAL로 추가한다. CANDIDATE/HOLD를 이름만 바꿔 수집하지 않는다. 승인된 공식 필드만 수집하며 원본·취득 시각·정규화 버전을 보존한다. 현재·예정뿐 아니라 최근 5건 심사 증거를 따로 남긴다. 신규 전시는 공통 sync, 기존 정본 재확인은 공통 refresh를 사용한다. 신규 기관을 ACTIVE로 자동 간주하거나 신규 수집을 자격 성공으로 대체하지 않는다.
2. **상세 API와 화면**: 내부 GET `/api/internal/v1/exhibitions/{id}/` 및 `/api/internal/v1/institutions/{id}/`를 추가한다. 검색과 같은 출처·적격성·최신성 게이트를 적용하고 비공개/없는 ID는 404로 처리한다. 전시 기본 정보, 안전한 미디어 표현, 확인된 가격·예약·관람시간·접근성·감각 상태, 운영일 근거와 명시 특성을 전달한다. 기관 상세는 기관 정보와 안전한 전시 목록을 제공한다. raw payload·인증 키·권리 미확인 이미지 URL을 전달하지 않는다. OpenAPI → 생성 TypeScript → Zod → UI를 맞춘다.
3. **관심·비교·최근 기록**: 전시·작품·기관 관심은 명시적 사용자 동작만 저장하며 서버 프로필을 만들지 않는다. 브라우저 저장 실패·무효 버전은 안전하게 복구한다. 비교는 전시 최대 3개, 상세와 관심 목록에서 이어지며 종료·취소·UNKNOWN을 명확히 표시한다. 최근 기록은 추천 학습에 쓰지 않는다. 검색어·좌표·추천 payload를 저장하지 않고, 취향·관심·최근 기록의 부분/전체 삭제를 제공한다.
4. **취향·작품 경로**: 기존 취향 명세의 매체·분위기·경험 코드와 명시 신호만 사용한다. 이미지 사용 권한이 확보되지 않은 자료를 임의 수집하거나 실제 작품으로 꾸미지 않는다. 테스트 중단·건너뛰기·결과 수정·추천 연결, 종료 전시/작품 관심의 특성 연결을 구현한다. 공식 작품 확보량과 데모를 구분한다.
5. **지도와 운영**: 지도 키가 설정된 일반 상세에서는 MapProvider를 자동 로드하고 검토된 장소 또는 공식 주소 위치를 바로 표시한다. 정상 표시 영역은 지도와 지도 안의 내 위치·확대·축소·전시장으로 돌아가기 조작만 제공하며 별도 제목·주소·성공 안내·외부 지도 링크를 두지 않는다. 미검토 장소의 검색 후보는 사용자가 선택한다. 사용자 위치 권한은 지도 안의 내 위치 버튼을 직접 눌렀을 때만 요청한다. 키 없는 실행·데모를 지원하고 정확 좌표를 서버 로그·영속 프로필에 보관하지 않는다. staff 전용 Django Admin과 `/admin/data-status/`를 연결한다. 상태 화면의 편집은 기존 Admin 레코드로 이동하며 별도 공개 편집기를 만들지 않는다. 일반 사용자 로그인을 추가하지 않는다.
6. **통합과 검증**: 전체 핵심 흐름의 브라우저 E2E, API 계약·DB migration·필수조건/UNKNOWN·권리·비영속 경계, 키 없는 실행과 Docker 재현을 검증한다. 기존 MIGAM 색·타이포·Radix 직접 사용을 유지하고 키보드·포커스·모션 감소·390px 반응형을 점검한다. 공개 운영의 서비스 키·비용·권한을 요구하기 전에 검토 가능한 배포 설정과 실행 문서를 완성한다.

## 작업 분담과 검증 증거

루트 작업자는 수집 확대와 통합을 소유한다. 독립된 상세 API 구현 1명만 병렬 위임하며 재위임·별도 브랜치·커밋·푸시는 하지 않는다. 작업 단위마다 관련 실패 테스트 → 구현 → 필요한 회귀 검증을 수행하고, 같은 코드와 외부 상태의 검증을 반복하지 않는다. 기존 변경은 요청 범위가 겹치는 곳만 최소 패치한다. 실제 데이터 증가량과 남은 UNKNOWN, 검증한 사용자 경로를 실행 기록에 추가한다.

- [x] 공식 기관 심사와 현재·예정 데이터 확대
- [x] 전시·기관 상세 API 및 UI
- [x] 명시적 관심·최근 기록·최대 3개 비교·초기화
- [ ] 취향 테스트와 작품 경로
- [x] 외부 지도 링크와 staff 조회 운영 화면
- [ ] 키 없는 재현·핵심 브라우저 E2E·배포 준비

2026-09-06 기본 취향·가상 작품 경로, 키 없는 단일 origin 실행과 핵심 브라우저 E2E까지 검증했다. 실제 작품 Source와 적응형 취향 세부 요구, Docker·호환성·공개 운영을 포함한 전체 항목은 아직 닫지 않는다. 최종 명령별 결과와 남은 순서는 [TP-008 검증 기록](../../06-quality/tp-008-verification.md)을 따른다.

### 2026-09-06 수집 확대 검증

기존 공식 SeMA CSV의 4개 물리 기관 최근 전시 20건이 20/20 CORE_PASS였다. `source-expansion-2026-09-06.json`에 심사 증거를 보존했다. sync의 반복 `--institution` 범위와 fixture 기관 격리를 포함한 관련 테스트 25개가 통과했다. 원 DB의 검증 백업 `db-20260906T112159Z-833998c2.sqlite3` 후 일반 sync run 7에서 468건 중 440건 VERIFIED, 28건 EXCLUDED, 격리 0건을 기록했다. 전체 전시는 758건, 기관 9곳, CURRENT 17건·UPCOMING 1건·ENDED 740건이다. 기존 정본과 원본 기록은 보존했고 자격 성공이나 ACTIVE 승격을 생성하지 않았다.

### 브라우저 상태와 경로 계약

2026-09-17 사용자는 더 이상 사용하지 않는 빵찾깅 앱을 미감으로 전환하고 기존 무료 쿼터 앱을 활용하도록 승인했다. 앱 ID `1528032`의 이름은 미감, 카테고리는 예술/디자인, 대표 도메인은 현재 홈 미리보기 주소로 변경했다. 카카오맵 ON과 일간 무료 쿼터 유지가 Developers 화면에서 확인됐다. 기존 JavaScript 키에 홈 미리보기 도메인과 `http://127.0.0.1:5173`을 등록하고, Git에서 제외된 `frontend/.env.development.local`의 `VITE_KAKAO_JAVASCRIPT_KEY`로 개발 환경의 기존 MapProvider를 연결한다. 테스트·홈 미리보기·운영 빌드에는 이 개발 전용 키를 자동 주입하지 않는다. 전용 앱 아이콘이 없어 기본 아이콘을 유지한다. 월렛·유료 API 설정과 공개 배포는 이 변경 범위에 포함하지 않는다. 키 없는 5180 `local-data` 실행과 5181 데모의 외부 SDK 비호출·가상 기관 경계는 유지한다. 아래 2026-09-06의 내장 지도 비활성 결정은 키를 주입한 일반 개발 환경에 한해 이 최신 결정으로 대체한다.

2026-09-17 초기 연결 검증(자동 표시 변경 전): 기존 DB를 읽기 전용으로 연 API와 Vite 5173에서 전시 `/exhibitions/324`의 명시적 검색으로 서울시립미술관 서소문본관·주차장 결과를 받았다. 본관(서울 중구 덕수궁길 61)을 선택한 뒤 지도 타일과 위치 마커를 확인했다. 내 위치 권한은 요청하지 않았다. `MapPanel.test.tsx` 3개가 통과했고 Vite 환경 로더에서 개발 모드에만 키가 존재하며 test·home-preview·production에는 없는 것을 확인했다. 키 값은 문서·추적 파일에 기록하지 않았다.

2026-09-06 카카오 지도 사용 설정에서 계정의 첫 앱(빵찾깅)만 무료이고 신규 미감 앱은 월렛·과금이 필요함을 확인했다. 사용자가 **외부 지도 링크 유지**를 선택했으므로 당시 릴리스는 내장 지도를 활성화하지 않았다. 미감 앱 ID 1568665는 개인·예술/디자인으로 생성했지만 카카오맵 OFF, 월렛 미연결, 키 미주입이었다. 당시 기존 앱 설정은 변경하지 않았다. 외부 카카오맵 장소 검색 링크를 P0 지도 경로로 확정하고, 내장 MapProvider는 선택 로드·실패 테스트만 보존했다.

2026-09-17 사용자 결정에 따라 상세 아래에 지도를 자동 표시하고 지도 주변의 제목·주소·성공 안내·외부 지도 링크를 제거한다. 앞선 명시적 지도 실행·검토 장소 선택 조건을 대체하며, 후속 요청에 따라 지도 안 오른쪽 위에 내 위치·확대·축소·전시장으로 돌아가기 아이콘 버튼을 배치한다. 각 버튼은 접근 가능한 이름과 키보드 포커스를 제공한다. 전시장으로 돌아가기는 최초 전시장 위치와 확대 수준으로 복귀한다. 지도 키가 설정된 일반 전시 상세 진입 시 Kakao SDK를 로드하고 아래의 제한된 장소 검색을 자동 실행한다. 기관·지역·실제 venue가 검토 대상과 일치하고 반환 장소명과 공식 도로명 주소가 검증된 후보는 바로 표시하며, 같은 주소의 적합한 후보가 여러 개면 검토된 대표 장소명을 우선한다. 미검토 장소의 후보는 사용자가 선택해야 하며 모호한 전시장·분관을 자동 확정하지 않는다. 장소명·주소와 공식 주소 위치의 한계는 스크린리더용 설명으로 제공할 수 있다. 지도에 표시해도 정본 위치를 변경하지 않는다.

검색 문자열은 기관명·실제 venue·확인된 지도 검색용 장소명과 지역 또는 검토된 공식 주소로 제한하고 사용자 원문 검색어를 넘기지 않는다. 상세 진입과 지도 자동 표시만으로 브라우저 위치 권한을 요청하지 않는다. 내 위치 버튼의 명시적 클릭 후에만 현재 위치를 한 번 요청하고, 받은 좌표는 현재 지도 표시의 메모리에서만 사용하며 서버·로그·브라우저 저장소에 보존하지 않는다. 위치 요청 중·거부·실패 안내는 지도 안의 닫을 수 있는 상태 메시지로 제공한다. 상세 전환·지도 해제 뒤 도착한 위치 응답은 무시한다. 로딩·SDK 실패·0건·미검토 후보 선택에는 필요한 짧은 안내를 표시하고, 다시 요청할 수 있을 때만 재시도를 제공한다. 키가 없으면 SDK를 호출하지 않고 비가용 안내만 표시한다. 지도 영역의 외부 검색·주소 검색·공식 위치 링크는 실패와 키 없는 상태에서도 반복하지 않으며, 공식 안내는 상단 관람 정보의 기존 전시 링크를 이용한다. 홈은 지도 SDK를 로드하지 않고 demo 모드는 키가 있어도 외부 지도를 사용하지 않는다. 공개 JavaScript 키는 `VITE_KAKAO_JAVASCRIPT_KEY`로만 주입하고 REST·관리자 키를 프론트에 두지 않는다.

2026-09-17 사용자는 세종 한 곳의 예외 처리를 현재 서비스하는 모든 기관으로 확대하도록 요청했다. 기관·지역·실제 전시장(venue)이 검토 범위와 모두 일치할 때 공식 장소명으로 우선 검색하고 기관명으로 보완한다. 미등록 전시장은 실제 venue와 기관명 순서로 검색한다. 중복을 제거하여 지역을 포함한 키워드 검색은 최대 2회이며, 적합한 결과가 없을 때만 다음 검색을 진행한다. 등록 대상은 검토한 장소명과 도로명 주소가 모두 일치하는 후보만, 미등록 대상은 지역이 일치하는 후보만 제공한다. 부속 카페·주차장과 다른 분관을 자동으로 선택하지 않는다.

이름 검색으로 적합한 장소를 찾지 못하면 검토된 공식 주소에 한해 Kakao Geocoder의 EXACT 주소 검색을 한 번 실행한다. 반환된 도로명 주소가 일치하는 결과는 `공식 주소 위치`로 자동 표시하고 전시실·입구를 확정하지 않는다. 이 구분은 지도 접근성 설명에도 유지한다. 검색 성공 또는 API 오류 뒤에는 추가 검색하지 않는다. 재시도는 이전 후보·지도를 비우며 상세 전환·화면 해제 뒤의 이전 검색 결과로 지도를 바꾸지 않는다. 정본 기관·주소·좌표를 변경하거나 좌표를 영속 저장하지 않는다. 세종 야외전시나 미등록 분관에는 실내 전시장 주소를 적용하지 않는다. 공식 주소 검토 근거와 전체 기관 확인 결과는 [지도 검색 검증](../../06-quality/map-search-verification.md)을 따른다.

2026-09-17 자동 표시 변경 전 검증: 초기 세종 재검색 검증에서는 지도 테스트 9개와 타입 검사가 통과하고 전시 `/exhibitions/1`의 지도 표시를 확인했다. 이후 다른 기관의 검색 누락과 관련 없는 후보 반환을 확인하여 공통 검색 계약으로 확대했다. 17개 전시·9개 기관의 venue가 검토 범위에 포함되며, 기관별 실제 검색·선택·지도와 9개 주소 검색을 확인했다. 지도·제품 통합 테스트 32개와 빌드가 통과했다. 이 결과는 자동 표시 동작의 검증을 뜻하지 않으며 변경 후 증거와 미등록 기관의 한계는 [지도 검색 검증](../../06-quality/map-search-verification.md)을 따른다.

상세·관심·비교·취향·내 데이터 관리 화면은 `/exhibitions/{id}`, `/institutions/{id}`, `/saved`, `/compare`, `/taste`, `/settings`에서 제공한다. 내부 이동은 메모리의 검색·조건 맥락을 유지하고 새 URL에 검색어나 추천 payload를 싣지 않는다. 홈은 API-free 경계를 유지한다. `migam:personal:v1`(데모는 별도 키)은 명시적 관심 ID, 취향 선택 코드, 최근 본 전시 ID 최대 20개만 저장한다. 비교 최대 3개는 탭 메모리에만 둔다. 저장 실패는 현재 세션 선택을 유지하며 알리고, 손상된 값은 폐기한다. 부분 삭제와 전체 삭제는 범위를 표시하고 Radix 확인 대화상자를 사용한다. 저장된 항목은 매번 API에서 재확인하며 찾을 수 없거나 비공개가 된 항목도 사용자에게 해제 수단을 제공한다.
