# 미감 P0 디자인 레퍼런스

## 1. 목적과 권위 경계

이 문서는 미감의 화면 명세와 UI 지침을 실제 화면 조합으로 이해할 수 있게 만든 **저충실도 디자인 표본**이다. 홈, 탐색, 상세, 관심, 비교와 주요 상태를 텍스트 와이어프레임으로 보여주며 구현 전 디자인 검토와 콘텐츠 우선순위 확인에 사용한다.

이 문서는 새로운 제품 요구사항이나 픽셀 단위 구현 계약을 만들지 않는다.

- 화면의 정보·행동·상태는 `screen-spec.md`가 기준이다.
- 화면 간 전이와 회복 경로는 `user-flows.md`가 기준이다.
- 색상·타이포그래피·이미지·모션·접근성 표현은 `ui-guidelines.md`가 기준이다.
- 충돌이 있으면 위 기준 문서를 따르고 이 표본을 갱신한다.
- 아래 전시명, 기관명, 날짜, 요금과 출처는 모두 문서 설명을 위한 가상 데이터다.
- 제목·전시명은 마루 부리, 본문·조작 UI는 SUIT로 확정했다. OD-004에는 최종 워드마크·로고 형식이 남아 있다.
- 공통 셸·홈·검색 표본은 현재 TP-006을 반영한다. 취향 테스트·상세·관심·비교·지도 등 나머지는 후속 P0 검토용이며 구현 상태를 나타내지 않는다. 현재 경로·미디어 계약은 [홈 설계](home-design.md)를 따른다.

## 2. 디자인 한 문장

> 따뜻한 중성색과 넓은 여백 위에서 전시 이미지와 타이포그래피가 발견을 이끌고, 방문 정보와 상태는 생활 도구처럼 명료하게 읽히는 에디토리얼 인터페이스.

미감의 시각적 인상은 다음 네 단어로 점검한다.

| 원칙 | 화면에서 보이는 모습 | 피해야 할 모습 |
| --- | --- | --- |
| 따뜻함 | 웜 아이보리·석회색의 낮은 채도 | 노란색이 강한 빈티지 장식 |
| 여백 | 큰 제목과 이미지가 숨 쉴 공간 | 정보가 빽빽한 대시보드 |
| 명료함 | 날짜·장소·요금·상태의 빠른 판독 | 장식 속에 방문 정보가 묻힘 |
| 절제 | 얇은 선, 각진 형태, 제한된 모션 | 강한 그림자, 과한 곡률, 카드 회전 |

## 3. 시각 시스템 표본

### 3.1 색상 역할

현재 색상 값은 [UI Guidelines의 기본 팔레트](ui-guidelines.md#41-기본-팔레트)를 따른다. 배경은 웜 아이보리, 홈 헤더·푸터는 석회색, 강조는 저채도 청회색을 사용한다. 전시·작품 이미지가 화면에서 가장 강한 색을 맡으며 상태는 색상만으로 표현하지 않는다.

### 3.2 타이포그래피 역할

```text
DISPLAY / 전시명 / 큰 섹션 제목
→ 마루 부리(Maru Buri), Serif

BODY / 방문 정보 / 검색 / 필터 / 버튼
→ SUIT, Sans-serif

EDITORIAL LABEL
→ SUIT + 절제된 자간
```

서체 역할은 화면 크기에 관계없이 유지한다. 긴 설명, 가격, 날짜, 접근성, 오류 문구는 장식보다 판독성이 높은 Sans-serif로 표시한다.

### 3.3 형태와 계층

```text
페이지
└─ 따뜻한 배경 + 넓은 바깥 여백
   ├─ 큰 Serif 제목
   ├─ 작은 에디토리얼 라벨
   ├─ 얇은 구분선
   └─ Surface 카드
      ├─ 각지거나 아주 작은 모서리 곡률
      ├─ 그림자 최소화
      └─ 충분한 내부 여백
```

큰 둥근 카드가 여러 겹 떠 있는 SaaS 대시보드 인상은 사용하지 않는다. 카드 계층은 그림자보다 여백, 선, 타이포그래피 크기와 정보 순서로 만든다.

### 3.4 브랜드 표본

```text
브랜드 히어로                       실용 UI

美感                                  미감
MIGAM                                 전시  탐색  취향  관심 목록

당신의 감각으로,
전시를 발견하다.
```

- `美感`과 `MIGAM`은 브랜드 영역에서 함께 사용할 수 있다.
- 내비게이션, 버튼, 모바일처럼 빠르게 읽어야 하는 곳에서는 `미감`을 사용한다.
- 푸터와 메타정보에서는 `美感 · MIGAM`을 사용할 수 있다.
- 기능·상태·방문 정보는 한국어가 기준이다.

## 4. 공통 셸

```text
[美感 · 미감 MIGAM → 홈]                    [영문 보조 라벨]
──────────────────────────────────────────────────────────
페이지 본문
──────────────────────────────────────────────────────────
美感 · 브랜드 문구        공식 출처 안내        MIGAM 라벨
```

TP-006의 데스크톱·모바일은 같은 정보 순서를 사용한다. 검색·추천은 홈 본문의 두 CTA와 탐색 탭으로 이동한다. 공통 헤더의 메뉴, 모바일 하단 내비게이션, 관심·내 데이터 관리 메뉴는 아직 제공하지 않는다. 홈 헤더는 데스크톱 스크롤에 따라 축소되고 모바일·탐색 헤더 높이는 유지된다.

## 5. 공통 컴포넌트 표본

### 5.1 에디토리얼 전시 카드

홈과 추천에서 감각적 발견을 우선하는 카드다.

```text
┌──────────────────────────────────────┐
│                                      │
│       [권리 확인 전시 이미지]       │
│                                      │
├──────────────────────────────────────┤
│ 지금 관람 가능                 ♡ 관심 │
│                                      │
│ 소리로 걷는 풍경                    │
│ Landscapes in Sound                  │
│                                      │
│ 미감 예시미술관 · 서울              │
│ 2026.08.01—11.03                     │
│                                      │
│ 사운드·설치 취향과 매체가 비슷해요. │
└──────────────────────────────────────┘
```

정보 순서는 이미지, 상태, 전시명, 장소·기간, 추천 이유다. 카드 추천 이유는 가장 강한 근거 하나만 보여준다.

### 5.2 카탈로그 전시 카드

탐색·검색·아카이브에서 비교와 판독을 우선하는 카드다.

```text
┌─────────────────────────────────────────────────────────────┐
│ [썸네일]  예정 · 2026.10.15 시작                            │
│           빛의 결                                           │
│           미감 예시공간 · 서울 중구                         │
│           사진 · 설치    성인 12,000원    예약 권장         │
│           [♡ 관심] [＋ 비교]                                │
└─────────────────────────────────────────────────────────────┘
```

상태, 날짜, 기관, 지역, 요금과 확인 필요 항목을 에디토리얼 카드보다 조밀하게 제공한다.

### 5.3 텍스트형 대체 카드

이미지를 사용할 수 없어도 카드 크기와 기능을 유지한다.

```text
┌──────────────────────────────────────┐
│ SOUND · INSTALLATION                 │
│ ───────────────────────────────      │
│                                      │
│ 소리로 걷는 풍경                    │
│ Landscapes in Sound                  │
│                                      │
│ 미감 예시미술관 · 서울              │
│ 2026.08.01—11.03                     │
│                                      │
│ 지금 관람 가능              ♡ 관심   │
└──────────────────────────────────────┘
```

- 웜 뉴트럴 바탕, Serif 전시명, 작은 매체 라벨과 최소한의 선만 사용한다.
- 매체를 임의의 화려한 색·패턴으로 번역하지 않는다.
- `LINK_ONLY`, `RIGHTS_UNKNOWN` 이미지는 요청하거나 핫링크하지 않는다.
- 이미지 부재를 낮은 추천 순위나 낮은 품질처럼 보이게 하지 않는다.

### 5.4 매체별 탐색 카드

```text
┌────────────────────────────┐  ┌────────────────────────────┐
│ 01 PAINTING             →  │  │ 02 SPACE                →  │
│                            │  │                            │
│ 그림과 평면 작품          │  │ 입체와 공간               │
│ 회화·드로잉·판화·서예     │  │ 조각·설치·건축·공간       │
└────────────────────────────┘  └────────────────────────────┘

┌────────────────────────────┐  ┌────────────────────────────┐
│ 03 CRAFT                →  │  │ 04 DIGITAL              →  │
│ 공예와 디자인              │  │ 영상과 디지털             │
│ 도자·공예·패션·디자인     │  │ 영상·애니메이션·미디어    │
└────────────────────────────┘  └────────────────────────────┘

┌────────────────────────────┐  ┌────────────────────────────┐
│ 05 SOUND                →  │  │ 06 INTERACTIVE          →  │
│ 소리와 공연               │  │ 직접 참여하는 작품        │
│ 사운드·퍼포먼스           │  │ 인터랙티브·관객 참여      │
└────────────────────────────┘  └────────────────────────────┘
```

hover와 focus에서는 배경 톤, 선과 작은 화살표의 변화를 제한적으로 사용할 수 있다. 클릭하면 해당 매체 필터가 적용된 전시 탐색으로 이동한다.

### 5.5 상태 라벨

```text
[● 지금 관람 가능]
[○ 곧 시작하는 전시 · 10월 15일]
[— 종료된 전시 · 현재 관람 불가]
[! 최근 운영 정보의 재확인이 필요합니다]
[? 요금 정보 확인 필요]
```

색·아이콘은 보조 수단이다. 텍스트 없이 원·느낌표·색상만 표시하지 않는다.

### 5.6 추천 이유

```text
카드
└─ 사운드·설치 취향과 매체가 비슷해요.

상세
└─ 이 전시를 추천한 이유
   ├─ 관심을 표시한 사운드·설치 전시와 매체가 비슷해요.
   ├─ 취향 테스트에서 몰입형 공간 경험을 선택했어요.
   └─ 관심 있는 기관에서 진행하는 현재 전시예요.
```

근거가 하나라면 하나만 표시한다. 문장 수를 맞추기 위해 이유를 만들지 않는다.

### 5.7 버튼·칩·관심 상태

```text
주요 행동       [내 취향부터 알아보기]
보조 행동       [지금 갈 전시 찾기]
텍스트 링크     전시 더 보기 →
외부 링크       공식 페이지에서 확인 ↗
적용된 필터     [서울 ×] [9/12 ×] [사운드 ×]
관심 전         [♡ 관심 있음]
관심 후         [♥ 관심 있음 · 선택됨]
```

선택과 해제는 색이나 하트 모양만으로 구분하지 않는다. 카드 전체 링크와 카드 안의 관심·비교 버튼은 각각 독립된 포커스 대상이다.

## 6. 화면별 저충실도 와이어프레임

### 6.1 `UX-001` 홈 — 데스크톱

```text
공통 헤더
가상 미술관 필름 + 공식 슬로건 + 한 문장 안내
[전시 둘러보기] [조건으로 추천받기]
──────────────────────────────────────────────────────────
01 공간의 온도    짧은 설명 + 넓은 공간 이미지
02 머무는 시선    짧은 설명 + 오른쪽에 배치한 이미지
03 재료의 감각    짧은 설명 + 여백을 둔 물성 이미지
──────────────────────────────────────────────────────────
어떤 전시가 끌리나요?    안내 + 두 탐색 CTA
공통 푸터
```

실제 전시 목록과 API 요청은 없다. 장식 미디어를 실제 전시 사실로 제시하지 않으며, 영상 실패·동작 줄이기에서는 정적 poster를 유지한다.

### 6.2 `UX-001` 홈 — 모바일

필름 대신 poster를 기본 표시하고 슬로건·안내·두 CTA를 세로로 배치한다. 세 장면은 각각 번호·제목·설명·이미지 순서로 읽고 마지막 안내와 푸터가 이어진다. 제목은 마루 부리, 안내와 CTA는 SUIT다. 페이지 스크롤바는 숨기되 스크롤·키보드 이동은 유지한다.

### 6.3 `UX-002` 취향 테스트

```text
┌────────────────────────────────────────────────────────────────────┐
│ YOUR TASTE                                      3 / 약 8           │
│ 좋아하는 감각과 관람 방식을 알아보는 테스트예요.                  │
│ 답변은 이 브라우저에만 저장됩니다.                                 │
│                                                                    │
│ 어떤 작품에 더 눈이 가나요?                    [결과 보기]        │
│                                                                    │
│ [작품 카드 □] [작품 카드 ■ 선택됨] [작품 카드 □] [작품 카드 □]  │
│                                                                    │
│ 여러 개를 선택해도 괜찮아요. 선택하지 않은 카드는 비선호가       │
│ 아닙니다.                                                          │
│                                                                    │
│ [이전]       [잘 모르겠어요] [건너뛰기]                [다음]     │
└────────────────────────────────────────────────────────────────────┘
```

경험 시나리오 문항은 다음처럼 텍스트만으로도 선택할 수 있다.

```text
┌────────────────────────────────────┐
│ 공간형 사운드 설치                │
│                                    │
│ 여러 방향에서 자연과 도시의       │
│ 소리가 들려옵니다. 관람객은        │
│ 공간을 천천히 이동합니다.          │
│                                    │
│ 소리 있음 · 자유 이동             │
│ 차분한 분위기 · 약 15~30분         │
└────────────────────────────────────┘
```

상황 비교 문항은 한쪽을 강제로 고르게 하지 않는다.

```text
어떤 감상 방식이 더 끌리나요?

[한 작품 앞에서 오래 머물기]    [공간을 이동하며 경험하기]

[왼쪽이 좋아요] [둘 다 좋아요] [오른쪽이 좋아요]
[잘 모르겠어요] [건너뛰기]
```

### 6.4 `UX-003` 취향 결과·프로필

```text
┌──────────────────────────────────────────────────────────────────┐
│ YOUR TASTE                                                       │
│ 지금 자주 나타나는 취향                                         │
│                                                                  │
│ 01  소리와 공간이 함께 있는 전시                                │
│     관심을 표시한 사운드·설치 전시가 자주 나타나요. [근거 보기] │
│                                                                  │
│ 02  차분하게 오래 머무는 감상                                    │
│     취향 테스트에서 몰입형 공간 경험을 여러 번 선택했어요.       │
│                                                                  │
```

### 6.6 `UX-004` 전시 탐색 — 모바일과 0건

모바일도 검색창과 결과 도구를 먼저 표시한다. 필터는 하단 시트로 열고 내부 스크롤과 닫기·적용 행동을 유지한다. 닫은 뒤 포커스는 필터 버튼으로 돌아간다. 결과가 없으면 적용 조건을 유지한 안내를 표시하며 필수조건을 자동으로 해제하지 않는다.

### 7.1 최초와 추가 로딩


### 7.3 이미지 권리 없음

```text
[텍스트형 대체 카드]

이미지를 표시할 수 없지만 전시명, 기간, 장소, 상태, 추천 이유,
관심, 비교와 상세 행동은 그대로 제공합니다.
```

권리 상태를 사용자에게 기술 코드로 노출할 필요는 없지만 이미지를 요청해서도 안 된다.

### 7.4 부분 오류와 지도 오류

```text
작품 결과를 불러오지 못했어요.
전시와 기관 결과는 그대로 볼 수 있습니다.
[작품 결과 다시 시도]

지도를 표시할 수 없어요.
같은 전시를 목록에서 계속 볼 수 있습니다.
[목록으로 돌아가기] [지도 다시 시도]
```

정상 콘텐츠와 입력 조건을 유지하고 실패한 영역 가까이에서 회복 행동을 제공한다.

### 7.5 전체 오류

```text
전시를 불러오지 못했어요.
입력한 서울 · 9/12 · 사운드 조건은 그대로 유지하고 있습니다.
[다시 시도] [홈으로 이동]
```

전체 오류에서도 사용자가 입력한 검색어·필터·비교 선택을 가능한 범위에서 유지한다. 마지막 검증값을 최신 정보처럼 가장해 표시하지 않는다.

### 7.6 위치 권한 거절

```text
현재 위치를 사용하지 않았어요.
지역을 직접 선택해 전시를 찾을 수 있습니다.
[지역 직접 선택]
```

권한을 반복 요청하거나 위치 거절을 오류처럼 비난하지 않는다.

### 7.7 관심·최근 본 전시 빈 상태

```text
관심 전시
아직 관심 있는 전시가 없어요.
나중에 다시 보고 싶은 전시의 ‘관심 있음’을 선택해보세요.
[전시 탐색]

최근 본 전시
최근에 열어본 전시가 없어요.
전시 상세를 보면 이 브라우저에서 다시 찾아볼 수 있어요.
이 기록은 추천 취향에 반영되지 않습니다.
[전시 탐색]
```

관심 목록은 전시·작품·기관 탭별로 해당 객체의 의미와 탐색 진입점을 제공한다. 빈 상태를 채우기 위해 가상 항목이나 자동 관심을 만들지 않는다.

## 8. 방문 정보와 사용자 문구 표본

### 8.1 요금

```text
관람료

성인             15,000원
청소년           10,000원
어린이            8,000원

우대·할인
65세 이상         무료
장애인             50% 할인

※ 실제 적용 조건과 최신 가격은 공식 페이지에서 확인해 주세요.
```

얼리버드·패키지·특별 프로그램은 기본 관람권과 분리한다. 동행자 예상 총액을 계산하지 않는다.

### 8.2 예약

```text
회차별 사전 예약이 필요한 전시입니다.
최신 회차와 예약 가능 여부는 공식 페이지에서 확인해 주세요.
[공식 예약 페이지 ↗]
```

예약 유형은 설명하되 잔여석·매진·실시간 예약 가능을 판정하지 않는다.

### 8.3 관심 피드백

```text
저장
관심 목록에 저장했어요. 비슷한 추천에 반영할게요.

해제
관심 목록에서 해제했어요.
```

해제를 `싫어요`나 부정 취향 학습으로 표현하지 않는다.

### 8.4 초기 개인화

```text
명시적 신호가 적을 때
아직 취향을 알아가는 중이에요.

신호가 쌓였을 때
관심을 표시한 전시를 바탕으로 추천하고 있어요.
```

한두 개의 관심만으로 고정된 취향을 단정하지 않는다.

## 9. 상호작용 상태 표본

| 요소 | Default | Hover | Focus | Selected | Disabled / Loading |
| --- | --- | --- | --- | --- | --- |
| 주요 버튼 | Surface 또는 Accent 행동 | 명도·선의 제한적 변화 | 두께와 대비가 충분한 포커스 링 | 해당 없음 | 이유 또는 진행 문구 제공 |
| 전시 카드 | 얇은 경계 | 경계·텍스트 링크 강조 | 카드 링크에 명확한 포커스 | 선택형 카드에는 텍스트 상태 | 핵심 정보를 흐리게 숨기지 않음 |
| 관심 | `♡ 관심 있음` | 행동명 유지 | 아이콘 주위가 아닌 전체 버튼 포커스 | `♥ 관심 있음 · 선택됨` | 저장 중임을 읽을 수 있게 알림 |
| 필터 칩 | 값과 해제 행동 | 해제 가능성 강조 | 칩 이름과 삭제 행동 노출 | 적용된 값 자체가 선택 상태 | 적용 불가 이유 제공 |
| 테스트 카드 | 미선택 | 카드 경계 변화 | 카드 전체 포커스 | 체크·텍스트·경계 함께 변경 | 이미지 실패 시 선택 불가 이유 |

일시적으로 열리는 대화상자·바텀시트·팝오버는 열릴 때 의미 있는 첫 요소로 포커스를 옮기고 닫힌 뒤 실행 요소로 돌려보낸다.

## 10. 반응형 전환표

| 화면·요소 | 데스크톱 | 태블릿 | 모바일 |
| --- | --- | --- | --- |
| 공통 내비게이션 | 상단 전체 메뉴 | 축약 상단 메뉴 | 하단 5개 메뉴 + 더보기 |
| 홈 히어로 | 타이포 + 이미지 2~3개 비대칭 | 이미지·타이포 비중 축소 | 1열 + 이미지 1~2개 |
| 추천 그리드 | 기본 3열 2행 | 2열 | 1열 |
| 탐색 목록 | 2~4열 카탈로그 그리드 | 2열 | 1열 |
| 상세 필터 | 우측 패널 | 오버레이 패널 | 바텀시트 |
| 전시 상세 | 히어로와 방문 패널 병치 | 두 영역 비율 축소 | 이미지·정보·본문 1열 |
| 비교 | 전시 최대 3열 표 | 가로 스크롤을 피한 축약 표 | 속성별 세로 카드·아코디언 |
| 지도 | 지도 + 우측 결과 요약 | 지도 + 하단 요약 | 지도와 목록 전환, 핀 요약 시트 |

반응형 전환 뒤에도 DOM 읽기 순서, 시각 순서와 키보드 포커스 순서를 일치시킨다.

## 11. 시각 접근성 검수 표본

```text
관심 상태
나쁜 예: 갈색 하트 아이콘만 표시
좋은 예: ♥ 관심 있음 · 선택됨

전시 상태
나쁜 예: 초록·회색 점만 표시
좋은 예: 지금 관람 가능 / 종료된 전시 · 현재 관람 불가

접근성 미확인
나쁜 예: 휠체어 접근 불가
좋은 예: 휠체어 접근 정보 확인 필요

이미지 없음
나쁜 예: 깨진 이미지 아이콘과 비활성 카드
좋은 예: 동일 정보·행동을 가진 텍스트형 대체 카드
```

다음 항목을 시각 검수와 별도로 실제 키보드·스크린리더·확대·모션 감소 환경에서 확인한다.

- 보이는 포커스와 논리적 포커스 순서
- 대화상자·바텀시트·팝오버 포커스 진입·유지·복귀
- 하트·필터·상태·오류의 접근성 이름
- 브라우저 확대 시 가로 스크롤 없이 핵심 과업 유지
- 모바일 터치 요소의 충분한 활성 영역과 간격
- `prefers-reduced-motion`에서 비필수 모션 제거
- 지도와 같은 정보를 제공하는 접근 가능한 목록

## 13. 구현 전 디자인 검토 체크리스트

- 화면이 `발견 → 이해 → 판단` 중 어떤 역할을 하는지 즉시 알 수 있는가?
- 방문에 필요한 상태·날짜·장소·요금·예약·접근성 정보가 장식보다 먼저 읽히는가?
- 에디토리얼 카드와 카탈로그 카드가 목적에 맞게 구분되는가?
- 이미지가 없어도 같은 정보와 행동을 제공하는가?
- 현재·예정·종료·취소·미확인을 텍스트로 구분하는가?
- 추천 이유가 카드 1개, 상세 최대 3개이며 실제 근거와 연결되는가?
- 필수 조건과 선호 조건이 시각적으로 구분되고 자동 완화되지 않는가?
- 데스크톱에서 모바일로 바뀌어도 읽기·포커스 순서가 유지되는가?
- 큰 곡률·강한 그림자·과한 모션이 에디토리얼 계층을 대신하지 않는가?
- 가상 표본을 실제 전시 사실이나 확정된 브랜드 자산으로 오해할 요소가 없는가?

## 14. 열린 결정

마루 부리·SUIT는 DEC-101로 확정했다. OD-004에는 최종 워드마크·로고 형식이 남아 있으며, 이 문서의 브랜드 표본은 최종 로고 자산 승인을 뜻하지 않는다.
