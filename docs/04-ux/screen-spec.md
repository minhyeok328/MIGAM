# 미감 P0 화면 명세

## 1. 목적과 경계

`TP-006` 2.2.1은 API를 호출하지 않는 브랜드 홈 `/`와 검색·추천을 소유하는 `/discover`를 분리한다. 전시·기관·전체 검색과 조건 추천, 안전한 카드·확인 필요·오류·빈 상태를 포함한다. 2026-09-05 승인된 검색 화면 간소화는 구현 후 재검토하는 임시 UI 범위이며 이 문서의 `DRAFT` 상태와 전체 P0 목표를 승인으로 바꾸지 않는다. 이 단계에는 미구현 관심·상세·지도·실제 취향 테스트 메뉴를 두지 않는다. 검색·추천 입력은 페이지 URL에 복제하지 않고 현재 탭 메모리에서 보존하며 `/discover#recommend`의 고정 fragment만 초기 탭 식별자로 사용한다. 아래 전체 P0 화면 표는 후속 목표이며 TP-006 전체 완료 범위가 아니다.

이 문서는 `UX-001`~`UX-013` 화면에서 무엇을 먼저 보여주고 어떤 행동과 상태를 제공할지 정한다. 세부 좌표, 픽셀 치수, 컴포넌트 구현 API는 정하지 않는다. 모든 화면은 반응형 한국어 웹이며, 공식 영문명이 존재하는 고유명과 제한된 에디토리얼 라벨만 영문을 병기할 수 있다.

## 2. 공통 셸과 내비게이션

현재 TP-006의 공통 헤더는 홈 링크인 로고와 영문 보조 라벨만 제공한다. 검색·추천 진입은 홈 본문의 두 CTA와 `/discover`의 탭이 담당한다. 푸터는 브랜드 문구·출처 안내이며 미구현 메뉴는 표시하지 않는다. 홈의 현재 구성과 미디어 경계는 [홈·탐색 분리 설계](home-design.md)를 따른다. 아래 2.1~2.3의 확장 내비게이션은 후속 P0 검토 범위다.

### 2.1 데스크톱

상단 내비게이션은 다음 구조를 사용한다.

```text
미감 로고 | 전시 | 탐색 ▾ | 취향 | 관심 목록 | 검색
```

`탐색`에는 작품·소장품, 기관, 매체별 탐색, 과거 전시 아카이브가 들어간다. 현재 위치와 날짜·지역은 전시 탐색 안에서 다룬다.

### 2.2 모바일

하단 내비게이션은 홈, 전시, 검색, 관심, 더보기를 제공한다. 더보기에는 취향, 작품·소장품, 기관, 과거 전시, 설정을 둔다. 현재 화면은 텍스트와 접근성 상태로도 알 수 있어야 한다.

### 2.3 전역 원칙

- 일반 사용자 로그인·계정 진입점을 두지 않는다.
- 검색, 관심, 비교, 내 데이터 관리는 키보드와 터치로 동일하게 완료할 수 있어야 한다.
- 새 화면으로 이동해도 검색어·필터·비교 선택 같은 작업 맥락을 가능한 범위에서 보존한다.
- 외부 공식 페이지 이동은 외부 링크임을 이름이나 보조 설명으로 알린다.

## 3. 공통 화면 요소

| 요소 | 명세 |
| --- | --- |
| 에디토리얼 전시 카드 | 홈·추천에서 이미지 또는 텍스트형 대체 표현, 전시명, 상태, 기간·장소, 핵심 이유 1개, 관심, 상세 진입을 제공한다. |
| 카탈로그 전시 카드 | 탐색·검색·아카이브에서 상태, 기간, 기관, 지역, 일반 요금, 매체, 확인 필요 항목, 관심·비교를 빠르게 읽게 한다. |
| 텍스트형 대체 카드 | 이미지와 같은 정보 위계와 행동을 유지한다. 이미지 URL을 요청하거나 빈 이미지 프레임을 노출하지 않는다. |
| 상태 라벨 | `현재`, `예정`, `종료`, `취소`, `최근 확인 필요`, `추가 확인 필요`를 텍스트로 표시한다. |
| 추천 이유 | 카드 1개, 전시 상세 최대 3개다. 실제 계산에 기여한 특성만 표시하고 적합도 퍼센트를 노출하지 않는다. |
| 필터 칩 | 적용된 조건을 읽을 수 있는 이름으로 표시하고 개별 해제할 수 있다. 하드 필터와 선호를 시각적으로 구분한다. |
| 관심 있음 | 전시·작품·기관에 같은 의미로 사용한다. 선택·해제 상태를 아이콘과 텍스트·접근성 이름으로 함께 제공한다. |
| 공식 출처 | 핵심 사실의 출처, 마지막 확인 시점, 공식 페이지 이동을 상세에서 제공한다. |
| 확인 필요 | 누락·충돌·오래된 정보를 `지원 안 함`, `무료`, `예약 불필요`처럼 단정하지 않는다. |

## 4. `UX-001` 홈

### TP-006 구현 경계

이번 승인 범위의 `/`는 `/discover`로 연결하는 이미지 중심 브랜드 진입 화면이다. 고정 헤더, 풀스크린 무음 필름과 HTML `h1`·짧은 안내·두 CTA, `01 공간의 온도`·`02 머무는 시선`·`03 재료의 감각`의 독립 이미지 섹션, 짧은 진입 제목·안내·검색·조건 추천 링크와 푸터 순서로 구성한다. 2026-09-05 최신 사용자 결정에 따라 번호·제목·짧은 설명 아래 큰 사진을 두는 처음의 섹션 구성을 복원한다. 긴 관점 선언문·장식용 영문 라벨·갤러리 공통 도입 문구는 제외한다. 공통 헤더에는 검색·추천 링크를 두지 않는다. 홈은 discovery provider와 API를 마운트하지 않는다. 실제 추천 전시 6개·전시 소식·매체·기관·취향 테스트는 아래 전체 P0 목표로 남겨 두며 이 패킷에서 정적 가상 데이터로 대체하지 않는다.

필름과 정적 이미지는 자체 생성한 가상 미술관 장식 자산이다. 실존 전시 사실이나 추천 근거로 캡션하지 않고 빈 대체 텍스트 또는 접근성 트리 제외를 적용한다. 의미 있는 워드마크·슬로건·링크는 HTML로 제공한다. `prefers-reduced-motion: reduce`, 모바일, 로딩·재생 실패에서는 WebP poster만으로 같은 정보와 행동을 제공한다.

### 목적

사용자가 자신의 상황에 맞는 두 출발점 중 하나를 즉시 선택하고, 아래에서 전시·매체·기관을 탐색하게 한다.

### 정보 순서

1. 브랜드 히어로
   - `당신의 감각으로, 전시를 발견하다.`
   - `아는 만큼 보는 대신, 좋아하는 것부터 시작해보세요.`
   - `내 취향부터 알아보기`, `지금 갈 전시 찾기`를 같은 중요도로 제공
2. 현재 추천 전시 6개
   - 취향 신호가 없으면 데이터 품질과 다양성 중심
   - 신호가 있으면 점진적으로 개인화
   - 같은 기관·매체의 과도한 반복을 줄이고 약 1개는 연결된 탐색형 후보를 지향
3. 전시 소식
   - `지금 볼 수 있어요`, `곧 시작해요` 탭
   - 상단 추천과 중복되면 가능한 후보 안에서 중복을 줄임
4. 매체별 탐색
   - 회화, 사진, 설치, 사운드, 영상·미디어아트 등을 이미지에 의존하지 않는 에디토리얼 텍스트 카드로 제공
5. 기관 영역
   - 관심 기관이 없으면 현재 전시 활동·데이터 품질·매체와 지역 다양성 중심
   - 관심 기관이 생기면 해당 기관의 현재·예정 전시를 우선 연결
6. 취향 신호가 없는 사용자에게 취향 테스트 진입을 다시 제공

### 반응형

- TP-006 데스크톱 히어로는 16:9 필름을 첫 화면 가까이 채우고, 시각 챕터는 풀폭 이미지와 큰 한국어 Serif 문장 사이에 충분한 수직 여백을 둔다. 후속 실제 추천 영역은 기본 3열 2행을 목표로 한다.
- 태블릿·모바일은 한 열로 쌓고 영상보다 poster와 카피를 우선한다. 제어 영역은 최소 44px 높이를 유지하며 가로 스크롤을 만들지 않는다.
- 이미지나 영상이 없거나 실패해도 문구와 두 CTA의 위치·읽기 순서는 유지한다.

## 5. `UX-002` 취향 테스트

### 주요 영역

- 테스트 목적과 브라우저 저장 안내
- 현재 진행 상태와 언제든 가능한 `결과 보기`
- 실제 작품·전시 카드 4개 복수 선택, 경험 상황 비교, 매체 복수 선택을 문항에 따라 제공
- `둘 다 좋아요`, `잘 모르겠어요`, `건너뛰기`
- 이전·다음 이동과 선택 상태 안내

### 콘텐츠 규칙

- 기본 약 8문항, 필요한 축에 한해 최대 4~6문항을 추가한다.
- 재사용 권리가 확인된 실제 이미지와 경험 시나리오를 혼합한다.
- 설명은 선택을 과도하게 유도하지 않도록 작품명·작가·매체·출처 중심으로 짧게 제공한다.
- P0에서 음원·영상은 직접 재생하지 않는다.
- 선택하지 않은 카드와 건너뛴 답은 부정 신호가 아니다.

### 상태

- 이미지 부재 카드는 시각 선택 문항에서 제외하고 경험 시나리오로 보완한다.
- 저장 오류가 있어도 응답을 즉시 잃지 않도록 현재 세션 상태를 유지하고 재시도를 안내한다.
- 키보드로 카드 선택과 선택 해제, 다음·이전·건너뛰기를 수행할 수 있어야 한다.

## 6. `UX-003` 취향 결과·프로필

### 주요 영역

- `지금 자주 나타나는 취향`을 매체·분위기·감상 방식의 정성 문장으로 요약
- 각 요약에 실제 테스트 선택 또는 관심 근거 연결
- 탐색 기록이 적은 축은 비선호가 아니라 `아직 탐색이 적어요`로 표현
- 취향이 비슷한 현재·예정 전시 카드
- 지역·날짜를 추가해 방문 가능한 추천으로 좁히는 진입
- `취향 테스트 다시 하기`와 `내 데이터 관리` 진입

적합도를 백분율이나 고정 성격 진단처럼 표현하지 않는다. 최신 재테스트 결과가 우선하되 사용자가 유지한 관심 신호는 계속 반영한다.

## 7. `UX-004` 전시 탐색

### TP-006 검색 구현 경계

- `/discover`는 작은 `전시 찾기` 제목과 검색·추천 탭 아래 검색창, 결과 수·`필터`·정렬, 적용 칩, 기본 전시 결과 순서로 구성한다. 큰 도입부·장식용 영문 라벨·반복되는 결과 제목은 두지 않는다.
- 검색 대상·시도·시군구·전시 상태는 처음에 숨기며 `필터` 버튼으로 Radix Dialog를 연다. 데스크톱 우측 패널과 모바일 바텀시트는 같은 primitive 전략을 사용한다.
- 필터를 열면 현재 적용값을 복사해 편집하고 `적용`으로 확정한다. 적용 없이 닫으면 draft를 버린다. 기본값이 아닌 적용 필터만 해제 가능한 칩으로 보이며 시·도 변경·해제는 시·군·구도 해제한다.
- 검색어는 버튼·Enter 제출, 필터는 `적용`, 정렬·칩 해제는 즉시 반영한다. 필터·정렬·칩은 현재 적용된 검색어를 기준으로 동작하고 입력창의 미제출 검색어는 보내지 않는다. 각 적용은 추가 페이지를 초기화한다.
- 첫 진입은 기본 전시 결과를 바로 요청한다. 기존 백엔드의 lifecycle·검색·정렬 의미, 24건 더 보기와 오류·0건·권리 경계는 유지한다. URL·저장·분석·API 계약을 변경하지 않으며 추천 폼·카드·홈도 이번 조정에 포함하지 않는다.

아래 상단 탐색·목록 규칙은 전체 P0 목표다. TP-006에는 위 경계를 우선 적용하며 아직 없는 필터·지도·정렬 선택지나 URL 입력 보존을 추가하지 않는다.

### 상단 탐색 영역

- 검색어 입력
- 핵심 필터: 지역, 날짜, 상태, 매체, 가격, 상세 필터
- 적용 칩, 총 결과 수, 정렬
- `지도에서 보기`

데스크톱 상세 필터는 우측 패널, 모바일은 바텀시트로 제공한다. 상세 조건에는 동행, 분위기, 예상 관람시간, 예약, 공간 유형, 행사 형식, 필수 접근성, 회피 감각 조건이 포함된다. 예상 관람시간과 예약은 각각 기본 `선호`와 명시적 `필수` 모드를 제공하고, `필수`일 때 정보 `UNKNOWN`은 조건을 충족하지 않는다는 도움말을 함께 표시한다. 분위기는 태그와 `UI Guidelines` 8.4의 정본 설명을 함께 표시하고 최대 3개까지 선택한다. 공간 유형과 행사 형식은 분리하며, 행사 형식의 공식 근거가 부족하면 `형식 미확인`으로 표시하고 제목·공간 유형·유사 매체로 추론하지 않는다.

### 목록 규칙

- 검색어가 없으면 현재·예정 전시가 기본이다. 종료 전시는 상태 필터로 선택한다.
- 무검색 기본 정렬은 현재 관람 가능, 조건·취향 적합, 종료 임박, 예정 시작 임박, 데이터 품질·완성도 순이다.
- 사용자는 `관련도순`, `추천순`, `최신 시작일순`, `종료 임박순`, `예정 시작일순`을 선택할 수 있다. 현재 상태나 선택 상태에 무의미한 정렬은 비활성화하거나 적용 기준을 투명하게 변환한다.
- 첫 24개 이후 `전시 더 보기`로 24개씩 추가한다.
- 필터 변경 시 목록 추가 상태를 초기화하며 URL에는 검색어·필터·정렬을 보존한다.
- 결과는 에디토리얼 카드보다 조밀한 카탈로그 카드로 표시한다.
- 현재·예정·종료·확인 필요를 섞어 보여줄 때 각 카드에서 상태를 즉시 구분한다.

### 0건 상태

- 현재 조건을 모두 보여준다.
- 시스템이 조건을 자동 변경하지 않는다.
- 분위기·매체 같은 선호 조정안을 먼저 제공한다.
- 예산은 사용자가 직접 선택할 때만 해제한다.
- 지역·날짜와 필수 접근성·회피 감각 조건은 완화 제안에 넣지 않는다.
- 필수로 지정한 예약·예상 관람시간도 시스템이 자동 완화하지 않는다.

## 8. `UX-005` 통합 검색

### 탭

`전체`, `전시`, `작품·소장품`, `기관`을 제공한다.

- 전체: 유형별 상위 결과와 전체 보기 링크
- 전시: 전시명·작가·기획자·기관·설명·매체·형식·지역·기간 검색
- 작품·소장품: 공식 데이터와 권리·핵심 메타데이터가 충분한 작품
- 기관: 기관명·지역·공간 유형과 현재 전시 여부

키워드가 있으면 종료 전시도 검색하며 관련도가 비슷한 결과 안에서 현재, 예정, 종료 순으로 상태를 우선한다. 검색어 일치와 명시 필터가 기본이고 개인화는 보조 신호다. `추천순`은 검색 조건을 만족한 후보 안에서만 개인화를 강화한다. 정렬 선택지와 상태상 무의미한 정렬의 처리 규칙은 `UX-004` 목록 규칙을 따른다. 독립 작가 탭은 없다.

### 상태

- 유형별 결과가 없으면 해당 탭의 빈 상태만 표시하고 다른 탭 결과는 유지한다.
- 통합 검색 일부 유형이 실패하면 성공한 유형은 표시하고 실패한 유형만 재시도할 수 있게 한다.

## 9. `UX-006` 전시 상세

### 상단

- 전시 상태, 전시명, 공식 영문명, 짧은 구조화 요약
- 관심 있음, 비교 추가
- 권리 확인 대표 이미지 또는 텍스트형 대체 표현
- 기간, 장소, 일반 요금, 예약, 주요 매체
- 정성 적합도와 추천 이유 최대 3개

### 본문 순서

1. 한눈에 보기
2. 공식 소개 또는 명확히 구분된 구조화 요약
3. 주요 매체·감상 경험
4. 참여 작가
5. 공식적으로 연결된 작품
6. 접근성·감각 주의정보
7. 비슷한 현재·예정 전시
8. 기관 정보
9. 공식 출처와 마지막 확인 시점

### 방문 정보 표현

- 요금 필터용 대표값은 일반 성인 기본권이다.
- 상세에는 공식 확인된 성인·청소년·어린이·우대·할인 등 주요 가격을 구조화한다.
- 얼리버드·패키지·특별 프로그램 요금은 기본 관람권과 분리한다. 동행자 총액은 계산하지 않는다.
- 예약은 필요·권장·시간 지정·현장·선착순·프로그램 전용·미확인을 구분하며 실시간 잔여석·매진을 판단하지 않는다.
- 예상 관람시간은 `공식`, `확인 필요`를 구분한다. 공식값이 없을 때 서비스 추정 범위를 만들지 않는다.

### 특수 상태

- 종료: 상단부터 `종료된 전시`, `현재 관람 불가`, `표시된 운영 정보는 과거 정보`를 전달한다.
- `STALE`: 최근 재확인이 필요함과 마지막 확인 시점을 표시하고 공식 페이지를 권한다.
- `UNVERIFIED`: 최소 품질 핵심 항목의 마지막 검증 근거가 남아 있는 경우에만 방문 가능성을 확인하기 어렵다는 경고와 남은 공식 출처를 제공한다.
- 정보 충돌: 최소 품질 핵심값 충돌은 사용자 상세에서 제외하고 운영 검토로 보낸다. 게이트 밖 방문 정보 충돌만 해당 항목을 `확인 필요`로 표시할 수 있다.
- 이미지 권리 미확인: 이미지를 불러오지 않고 동일한 정보·행동을 제공한다.

## 10. `UX-007` 작품·소장품 상세

### 상단

- 권리 확인 대표 이미지 또는 텍스트형 대체 표현
- 작품명, 작가, 시대·제작연도, 매체·재질, 문화권, 소장기관
- 한국 작품과 국내 기관 소장 작품의 구분
- 관심 있음

### 본문 순서

1. 한눈에 보기
2. 공식 설명 또는 구조화 요약
3. 시대, 매체, 주제, 재질·기법, 근거 있는 감각 특성
4. 메타데이터 기반 비슷한 작품과 실제 일치 이유
5. 같은 작가의 작품
6. 같은 기관의 작품
7. 공식적으로 연결된 관련 전시
8. 출처와 이미지 이용조건

이미지 임베딩 유사도는 P0에서 사용하지 않는다. 작품이 같은 작가·기관에 속한다는 이유만으로 특정 전시 출품작이라 표시하지 않는다.

## 11. `UX-008` 기관 상세

### 상단 방문 정보

- 기관명, 공간 유형, 지역, 관심 있음
- 주소, 운영시간, 휴관일, 공식 홈페이지, 접근성 정보

### 탐색 영역

- 현재 전시, 예정 전시, 과거 전시
- 실제 등록 전시에서 집계한 자주 나타나는 매체
- 사용자의 취향 신호가 있으면 그 근거와 함께 가까운 전시

주관적인 공간 평가를 임의 생성하지 않는다. 운영시간·휴관·접근성이 미확인이면 공식 페이지 확인을 안내한다.

## 12. `UX-009` 관심 목록

### 기본 탭

- 전시
- 작품·소장품
- 기관

### 자동 분류

- 관심 전시: 지금 관람 가능, 곧 시작, 종료 임박, 종료된 전시
- 관심 기관: 현재 전시가 있는 기관, 예정 전시가 있는 기관, 현재 등록 전시가 없는 기관

상태 변경 후에도 관심을 유지하며 자동으로 올바른 그룹으로 이동한다. 작품은 시대·매체·소장기관을 보여주고 비슷한 작품과 공식 연결 전시로 이동할 수 있다.

### 빈 상태

각 탭의 의미를 설명하고 전시 탐색, 작품 탐색, 기관 탐색으로 연결한다. 사용자 지정 폴더·목록 공유·직접 순서 편집·알림 진입점은 제공하지 않는다.

## 13. `UX-010` 전시 비교

### 공통 비교 속성

- 정성 취향 적합도와 추천 이유
- 상태, 기간, 장소, 일반 요금
- 주요 매체, 분위기, 감상 방식
- 예약, 관람시간, 접근성, 감각 주의
- 상세, 공식 페이지, 관심 있음

데스크톱은 전시를 열로 둔 최대 3열 비교표다. 모바일은 속성별 세로 카드·아코디언에서 각 전시 값을 연속해 읽게 한다. 값이 다른 항목은 가볍게 강조하되 색상만 사용하지 않는다.

- 네 번째 추가 요청에는 최대 3개 제한과 제거 방법을 안내한다.
- `확인되지 않음`과 `조건 불충족`을 다른 텍스트로 표현한다.
- 종료 전시는 상단부터 `현재 관람 불가`를 표시하고 운영값이 과거 정보임을 고정 안내한다.
- 퍼센트와 자동 순위는 표시하지 않는다.

## 14. `UX-011` 지도 보기

- 전시 탐색의 현재 결과와 필터를 그대로 사용한다.
- 핀은 기관 위치를 기준으로 하며 동일 기관의 여러 전시를 묶어 전시 수를 보여줄 수 있다.
- 핀 선택 시 기관명, 전시명, 현재·예정 상태, 간단한 방문 정보, 관심, 상세 이동을 제공한다.
- 목록으로 돌아가기와 지도 재시도를 항상 제공한다.
- 위치 권한은 `현재 위치로 찾기`를 누른 뒤 요청한다. 거절·실패 시 수동 지역 선택으로 전환한다.
- 좌표가 없거나 지도 제공자가 실패한 항목은 목록에서 계속 탐색할 수 있다.
- 길찾기, 이동시간, 관람 동선, 교통, 식당·카페는 표시하지 않는다.

## 15. `UX-012` 내 데이터 관리

### 안내

- 미감은 회원가입 없이 이용하며 취향·관심·최근 본 전시는 현재 브라우저에 저장됨
- 브라우저 데이터 삭제나 다른 브라우저에서는 유지되지 않음
- 현재 위치는 사용자가 요청한 현재 검색에만 사용함

### 행동

1. 취향 테스트 다시 하기
2. 관심 목록 초기화
3. 취향 데이터 초기화
4. 모든 로컬 데이터 삭제

각 행동 전에 삭제·유지 범위를 보여준다. `모든 로컬 데이터 삭제`는 복구 불가를 설명하는 확인 대화상자를 사용하며 실행 후 홈과 취향·관심·최근 본 상태를 즉시 초기화한다.

## 16. `UX-013` 최근 본 전시

- 최근 열어본 전시를 최근 순으로 최대 10~20개 제공한다.
- 같은 전시는 하나만 유지하고 다시 열면 순서만 갱신한다.
- 현재·예정·종료 상태를 최신 표시값으로 보여준다.
- 전시 상세 재방문을 제공하며, 기록은 취향 신호로 사용하지 않는다.
- 빈 상태에서는 전시 탐색으로 연결한다.

## 17. 공통 상태 명세

| 상태 | 화면 표현 | 금지되는 표현·행동 |
| --- | --- | --- |
| 최초 로딩 | 영역 제목과 예상 정보 구조를 유지하는 스켈레톤, 읽을 수 있는 로딩 문구 | 빈 화면, 상태를 애니메이션에만 의존 |
| 추가 로딩 | 기존 결과 유지, 더 보기 버튼 위치에서 진행 표시 | 기존 결과 삭제, 중복 요청으로 같은 항목 추가 |
| 빈 상태 | 빈 이유, 현재 조건, 다음 탐색 행동 | 사용자가 선택하지 않은 조건 자동 변경 |
| 전체 오류 | 실패 영역, 다시 시도, 안전한 이전 경로 | 입력 조건 삭제, 미확인 캐시값을 최신처럼 표시 |
| 부분 오류 | 성공 영역 유지, 실패 영역만 경고·재시도 | 전체 페이지를 불필요하게 막음 |
| 이미지 없음·권리 없음 | 텍스트형 대체 카드와 동일 행동 | 핫링크, 빈 깨진 이미지, 낮은 정보 위계 |
| 종료 전시 | 종료·현재 관람 불가·과거 정보 경고 | 현재 추천·현재 방문 가능 표현 |
| 공식 취소 전시 | 취소·현재 관람 불가·공식 확인 근거 | 현재 추천·대체 일정 추정 |
| `STALE` | 마지막 확인 시점과 재확인 필요 | 최신 정보처럼 무경고 표시 |
| 최소 품질을 통과한 `UNVERIFIED` | 추가 확인 필요 영역, 방문 불확실성, 공식 출처 | 홈·일반 추천 노출, 조건 충족으로 간주 |

## 18. 접근성·반응형 검수 기준

- 읽기 순서, 시각 순서, 키보드 포커스 순서를 일치시킨다.
- 모든 링크·버튼·필터·카드 선택에 보이는 포커스 상태를 제공한다.
- 대화상자, 바텀시트, 팝오버의 포커스를 관리하고 닫힌 뒤 실행 요소로 되돌린다.
- 관심, 상태, 오류, 필터 선택을 색상·아이콘 하나로만 구분하지 않는다.
- 정보 이미지에는 맥락에 맞는 대체 텍스트, 장식 이미지는 빈 대체 텍스트를 사용한다.
- 확대를 제한하지 않으며 모바일 터치에서도 핵심 과업을 완료할 수 있게 한다.
- `prefers-reduced-motion`에서 비필수 fade·slide 효과를 제거하거나 즉시 완료한다.
- 지도 기능을 사용할 수 없어도 같은 전시를 목록에서 찾고 상세로 이동할 수 있다.
