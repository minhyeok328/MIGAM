# 미감 P0 UI 지침

## 1. 디자인 목표

미감의 시각 언어는 **미술관 에디토리얼의 여백과 타이포그래피**에 **생활형 전시 탐색의 명료함**을 결합한다. 홈과 상세에서는 감각적인 발견을 돕고, 검색·필터·비교에서는 정보 판독을 우선한다.

화려한 장식이나 특정 전시 포스터가 서비스의 의미를 대신하지 않는다. 실제 전시·작품 이미지가 화면에서 가장 강한 색을 담당하고 UI는 따뜻한 중성색, 얇은 선, 넓은 여백으로 이를 받친다.

## 2. 브랜드 표기

| 맥락 | 표기 |
| --- | --- |
| 브랜드를 강하게 보여주는 히어로·워드마크 영역 | `美感` |
| 내비게이션·버튼·설정·안내 등 실용 UI | `미감` |
| 영문 보조 표기가 필요한 브랜드 맥락 | `MIGAM` |

- 서비스명은 `미감(美感 / MIGAM)`이다.
- 메인 슬로건은 `당신의 감각으로, 전시를 발견하다.`다.
- 보조 문구는 `아는 만큼 보는 대신, 좋아하는 것부터 시작해보세요.`다.
- `美感`만 반복 사용해 서비스 이름을 읽기 어렵게 만들지 않는다.
- 최종 워드마크 형식과 폰트 패밀리는 `OD-004`에서 결정한다. 이 결정 전에는 후보 글꼴을 최종 브랜드 자산으로 승인하지 않는다.

## 3. 언어와 문체

### 3.1 언어

- 기능·상태·오류·접근성·방문 정보의 기준 언어는 한국어다.
- `NOW EXHIBITING` 같은 짧은 에디토리얼 라벨과 공식 영문 고유명은 보조로 사용할 수 있다.
- 영문만으로 버튼, 상태, 필수 방문 정보를 전달하지 않는다.
- P0에는 언어 전환과 전면적 다국어 UI가 없다.

### 3.2 문체

- 전문 지식을 시험하지 않고 사용자의 감각을 존중하는 말투를 사용한다.
- `당신은 사운드 아트를 좋아합니다`보다 `지금 선택에서는 소리와 공간을 함께 경험하는 전시에 관심이 자주 나타났어요`처럼 현재 근거와 한계를 드러낸다.
- 확인되지 않은 정보는 `없음`이나 `지원 안 함`으로 바꾸지 않고 `정보 확인 필요`로 표현한다.
- 오류 문구는 원인, 보존된 상태, 다음 행동 순서로 쓴다.
- 종료 전시는 `현재 관람 불가`, 예상 관람시간 미확인은 `정보 확인 필요`처럼 오해 가능성을 직접 해소한다. 서비스가 추정 관람시간을 만들지 않는다.
- 추천 이유는 계산 근거를 평이한 말로 바꾸되 새로운 사실을 만들지 않는다.

## 4. 색상

### 4.1 기본 팔레트

| 역할 | 값 | 사용 |
| --- | --- | --- |
| Background | `#F7F5F0` | 페이지 기본 배경 |
| Surface | `#FCFBF8` | 카드·패널·대화상자 배경 |
| Primary Text | `#25221F` | 제목·본문·핵심 아이콘 |
| Secondary Text | `#716B64` | 보조 설명·메타데이터 |
| Border | `#DDD8D0` | 구분선·입력 경계·카드 외곽선 |
| Accent Brown | `#755A46` | 주요 버튼·관심·선택 상태의 제한적 강조 |

### 4.2 사용 규칙

- Accent Brown은 한 화면의 모든 요소에 넓게 칠하지 않고 행동과 선택 상태에 제한한다.
- 현재·예정·종료·확인 필요 상태는 색상뿐 아니라 텍스트, 아이콘 또는 형태를 함께 사용한다.
- 본문과 상호작용 요소의 실제 색 조합은 접근성 대비 검증을 통과해야 한다. 보조 텍스트를 중요한 안내나 오류의 유일한 색으로 사용하지 않는다.
- 전시 이미지 위 텍스트는 이미지 색에 의존하지 않는 독립 배경이나 충분한 오버레이를 사용한다.
- 카드 그림자는 최소화하고 여백과 1px 경계로 계층을 만든다.
- 다크 모드는 P0 범위가 아니다.

## 5. 타이포그래피

### 5.1 역할

| 역할 | 서체 계열 | 적용 |
| --- | --- | --- |
| Display / Exhibition Title | 한국어 Serif | 홈 히어로, 전시명, 큰 섹션 제목 |
| Body / UI | 한국어 Sans-serif | 본문, 검색, 필터, 버튼, 날짜, 가격, 상태 |
| Editorial Label | Sans-serif, 절제된 넓은 자간 | 짧은 영문 또는 한글 보조 라벨 |

- 긴 설명문과 방문 정보는 Sans-serif를 사용한다.
- 모바일에서는 큰 Serif 제목의 크기와 줄 길이를 줄여 본문보다 먼저 읽히되 화면을 독점하지 않게 한다.
- 영문 자간 스타일을 긴 한국어 문장에 그대로 적용하지 않는다.
- 글꼴 다운로드 실패 시에도 정보 위계와 레이아웃이 무너지지 않는 대체 계열을 둔다.
- 최종 Serif·Sans 패밀리는 `OD-004`의 결정 대상이다. 역할 자체는 열린 결정과 무관하게 유지한다.

## 6. 레이아웃과 공간

### 6.1 데스크톱

- 12컬럼 에디토리얼 그리드를 기본 구조로 사용한다.
- 홈·상세는 큰 여백, 비대칭 이미지와 타이포 조합을 허용한다.
- 탐색은 2~4열의 큰 카드 그리드를 사용하며 지나치게 조밀한 핀터레스트형 배치를 피한다.
- 비교는 최대 3개 전시를 열로 놓되 행 제목과 전시 머리글이 명확히 연결되어야 한다.

### 6.2 모바일

- 핵심 콘텐츠는 1열 읽기 순서를 기본으로 한다.
- 필터는 바텀시트, 비교는 속성별 세로 카드·아코디언으로 바꾼다.
- 에디토리얼 비대칭을 유지하더라도 본문과 CTA의 읽기 순서를 바꾸지 않는다.
- 고정 하단 내비게이션이 버튼·오류·더 보기 결과를 가리지 않게 한다.

### 6.3 형태

- 카드와 버튼은 큰 둥근 모서리, 강한 그림자, 대시보드형 떠 있는 패널을 기본 스타일로 삼지 않는다.
- 각진 모서리, 얇은 선, 충분한 내부 여백으로 정보 계층을 만든다.
- 긴 목록에서 카드 높이를 기계적으로 맞추기 위해 핵심 상태·기간·장소를 잘라내지 않는다.

## 7. 이미지와 권리

### 7.1 표시 가능 조건

- `REUSE_ALLOWED`인 전시·공간·작품 이미지만 서비스 안에서 표시하고 허용 범위 내에서 썸네일을 만든다.
- `LINK_ONLY`, `RIGHTS_UNKNOWN` 이미지는 복제·캐시·재호스팅·핫링크하지 않는다.
- 포스터 사용 권리가 작품 이미지에도 적용된다고 추정하지 않는다.

### 7.2 텍스트형 대체 카드

이미지 사용이 불가능한 전시는 웜 뉴트럴 배경, Serif 전시명, 작은 매체 라벨, 최소 기하 요소를 조합한 편집형 카드로 표시한다.

- 이미지 카드와 카드 크기·핵심 정보·관심·비교·상세 행동을 동일하게 유지한다.
- 매체별로 화려한 색이나 패턴을 자동 부여해 사실 정보처럼 보이게 하지 않는다.
- 이미지 부재를 낮은 품질이나 낮은 추천 순위의 시각적 신호로 만들지 않는다.
- 깨진 이미지 아이콘이나 빈 회색 사각형을 최종 상태로 남기지 않는다.

### 7.3 대체 텍스트

- 작품·전시 이미지가 이해에 기여하면 화면 맥락에 맞는 대체 텍스트를 제공한다.
- 인접 텍스트가 작품명·전시명만 반복하면 대체 텍스트에 같은 문자열을 불필요하게 중복하지 않는다.
- 장식적 선·도형·중복 썸네일은 빈 대체 텍스트를 사용한다.
- 공식 설명에 없는 시각적 의미, 분위기, 인물 정체를 임의로 서술하지 않는다.

## 8. 카드와 핵심 컴포넌트

### 8.1 전시 카드

- 홈·추천의 에디토리얼 카드와 검색·아카이브의 카탈로그 카드를 구분한다.
- 에디토리얼 카드는 이미지·전시명·핵심 이유가 먼저, 카탈로그 카드는 상태·기간·기관·요금·매체의 비교 가능성이 먼저다.
- 카드 전체 클릭과 내부 관심·비교 버튼이 충돌하지 않게 독립된 포커스 대상을 사용한다.
- 종료·미확인 상태는 카드 상단 또는 제목 인접 위치에서 먼저 읽힌다.

### 8.2 버튼과 링크

- 주요 CTA는 행동을 직접 설명한다: `내 취향부터 알아보기`, `전시 더 보기`, `모든 로컬 데이터 삭제`.
- 파괴적 행동은 Accent Brown의 일반 주요 버튼과 형태 또는 문구가 구분되어야 하며 확인 대화상자를 사용한다.
- 비활성화 상태는 낮은 대비만으로 전달하지 않고 사용할 수 없는 이유를 제공한다.
- 외부 공식 링크는 서비스 내부 이동과 구분한다.

### 8.3 관심 있음

- 하트 아이콘은 보조 표현이며 접근성 이름과 상태 문구를 제공한다.
- 선택 후 `관심 목록에 저장했어요. 비슷한 추천에 반영할게요.`처럼 저장과 취향 반영을 함께 안내할 수 있다.
- 해제는 `싫어요`나 부정 학습으로 표현하지 않는다.

### 8.4 필터·칩

- 필수 조건과 선호 조건은 그룹 제목·설명으로 구분한다.
- 적용된 값은 결과 상단 칩으로 표시하며 칩 해제 후 결과 변화를 알린다.
- 0건 조정 제안은 접근성·감각 필수조건을 포함하지 않는다.

#### 분위기

분위기는 태그와 아래의 짧은 설명을 함께 표시한다. 이 표가 P0 분위기 설명의 정본이다.

| 분위기 태그 | 설명 |
| --- | --- |
| 차분한 | 조용히 천천히 머물며 감상 |
| 몰입형 | 소리·영상·공간에 둘러싸여 감상 |
| 활기찬 | 색채·움직임·에너지가 강한 경험 |
| 사유형 | 작품의 의미를 생각하며 보는 전시 |
| 참여형 | 직접 조작하거나 움직임에 반응 |
| 실험적 | 낯선 매체와 새로운 표현을 탐색 |

- 사용자는 최대 3개를 선택할 수 있으며, 선택하지 않아도 탐색할 수 있다.
- 분위기는 필수 조건이 아닌 소프트 선호다. 근거가 미확인인 전시에 태그를 임의로 붙이거나, 선택하지 않은 태그를 비선호로 해석하지 않는다.

#### 공간 유형과 행사 형식

- 공간 유형과 행사 형식은 별도 필터와 칩으로 표시한다.
- 행사 형식의 공식 근거가 부족하면 `형식 미확인`으로 표시한다. 제목, 공간 유형, 유사 매체를 근거로 행사 형식을 추론하지 않는다.
- `형식 미확인`은 하나의 행사 형식 선택값이나 조건 충족값처럼 표시하지 않는다.

#### 정렬

- 정렬 선택지는 `관련도순`, `추천순`, `최신 시작일순`, `종료 임박순`, `예정 시작일순`이다.
- 현재 상태·선택한 상태에 의미가 없는 정렬은 비활성화하거나, 적용되는 정렬 기준을 사용자가 알 수 있게 투명하게 변환한다. 비활성화만으로 끝내지 않고 이유를 함께 제공한다.

### 8.5 대화상자·바텀시트·팝오버

- 제목, 목적, 닫기, 주 행동을 명확히 제공한다.
- 열릴 때 의미 있는 첫 요소로 포커스를 옮기고 배경과 포커스를 분리한다.
- 닫힌 뒤 실행 요소로 포커스를 돌려보낸다.
- ESC, 닫기 버튼, 취소 행동을 지원하되 파괴적 작업 중 임의 실행으로 닫히지 않게 한다.

## 9. 정보 상태 표현

| 상태 | 기본 문구 방향 | 행동 |
| --- | --- | --- |
| 현재 | `지금 관람 가능` | 상세·관심·비교·공식 페이지 |
| 예정 | `곧 시작하는 전시`와 시작일 | 상세·관심·비교·공식 페이지 |
| 종료 | `종료된 전시 · 현재 관람 불가` | 상세·관심·비교·비슷한 현재 전시 |
| 취소 | `취소된 전시 · 현재 관람 불가`와 공식 확인 근거 | 공식 페이지 확인 |
| `STALE` | `최근 운영 정보의 재확인이 필요합니다`와 마지막 확인 시점 | 공식 페이지 확인 |
| 최소 품질을 통과한 `UNVERIFIED` | `방문 가능성을 확인하기 어렵습니다` | 남아 있는 공식 출처 확인 |
| 값 미확인 | `요금/예약/접근성 정보 확인 필요` | 해당 공식 출처 확인 |
| 조건 불충족 | `선택한 조건과 맞지 않음` | 조건 확인·사용자 주도 수정 |

`미확인`과 `불충족`, `종료`와 `취소`, `무료`와 `요금 미확인`을 같은 배지나 문구로 합치지 않는다.

## 10. 로딩·빈 상태·오류

### 로딩

- 스켈레톤은 실제 정보 구조와 유사하게 하되 깜빡임이 핵심 상태를 대신하지 않게 한다.
- 추가 로딩은 기존 결과를 유지하고 버튼의 상태와 읽을 수 있는 진행 문구로 알린다.
- 사용자의 모션 감소 설정에서는 반복적인 반짝임을 제거한다.

### 빈 상태

- 단순 장식 일러스트보다 왜 비었는지, 어떤 조건이 적용됐는지, 다음 행동이 무엇인지 먼저 보여준다.
- 검색 0건에서 조건을 자동으로 완화하지 않는다.
- 관심·최근 본 전시 빈 상태에서는 해당 기능의 의미와 탐색 링크를 제공한다.

### 오류

- 오류를 페이지 전체가 아니라 실패한 범위에 가깝게 표시한다.
- 정상 콘텐츠와 사용자의 입력은 유지한다.
- `다시 시도`, `목록으로 돌아가기`, `지역 직접 선택`, `공식 페이지 확인`처럼 실제 회복 행동을 제공한다.
- 기술 예외 문자열, 출처 내부 식별자, 정확한 위치 좌표를 사용자 메시지에 노출하지 않는다.

## 11. 모션

- 홈과 상세에서 느리고 짧은 fade-up 또는 작은 slide를 제한적으로 사용한다.
- 이미지 확대, 카드 회전, 과도한 패럴랙스처럼 탐색을 방해하는 효과는 사용하지 않는다.
- 모션은 상태·성공·오류의 유일한 전달 수단이 아니다.
- `prefers-reduced-motion`에서는 비필수 전환을 제거하거나 즉시 완료한다.
- 콘텐츠가 들어오며 포커스 대상이나 스크롤 위치가 예기치 않게 이동하지 않게 한다.

## 12. 접근성 기본값

- 키보드만으로 홈의 두 CTA부터 관심·비교·초기화까지 핵심 과업을 완료할 수 있어야 한다.
- 모든 상호작용 요소에 보이는 포커스 표시를 둔다.
- 논리적 헤딩 구조, 랜드마크, 목록·표 의미를 마크업에 보존한다.
- 상태·관심·필터·오류를 색상·아이콘·위치 하나에만 의존하지 않는다.
- 브라우저 확대를 제한하지 않는다. 확대와 긴 한국어 텍스트에서도 가로 스크롤 없이 핵심 과업을 유지한다.
- 터치 요소가 서로 겹치거나 너무 가까워 오작동하지 않게 충분한 활성 영역과 간격을 둔다.
- 지도는 보조 보기이며 같은 결과를 접근 가능한 목록으로 항상 제공한다.
- 자동 접근성 검사와 키보드·스크린리더·확대·모션 감소의 핵심 흐름 검증을 함께 수행한다.

## 14. 사용하지 않는 패턴

- 로그인 유도, 계정 생성, 서버 프로필 상태
- 사용자 컬렉션·폴더·공유·공개 리뷰·평점

- 색상만으로 현재·예정·종료·확인 필요를 구분하는 배지

## 15. 열린 결정

`TP-006`의 첫 발견 화면은 Radix 직접 사용, 텍스트형 전시 카드, 검색·추천 탭과 반응형 조건 패널로 위 기준을 적용한다. OlfIt의 여백·구분선·입력/결과 연결 방식만 참고하며 자산·코드·정확한 구도는 복제하지 않는다. 외부 웹폰트를 불러오지 않고 시스템 Serif/Sans 계열을 사용한다.

- `OD-004`: 타이포그래피형 워드마크와 별도 로고 중 하나를 선택하고, Serif·Sans 최종 폰트를 확정해야 한다. 이 결정은 브랜드 자산과 폰트 라이선스 검토에 영향을 주지만 본 문서의 정보 위계·접근성·서체 역할 원칙을 바꾸지 않는다.
