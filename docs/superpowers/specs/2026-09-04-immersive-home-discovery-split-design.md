# 몰입형 홈과 전시 탐색 경로 분리 설계

## 목표

Houston Group에서는 고정 헤더, 첫 화면을 채우는 미디어, 큰 선언문과 풀폭 콘텐츠가 차례로 나타나는 에디토리얼 리듬만 참고한다. 색·서체·이미지·문구·구체적인 모션은 복제하지 않는다. 미감의 홈은 조용한 전시 경험에 맞는 낮은 채도와 자연광 중심의 자체 생성 미디어를 사용하고, 정보 밀도가 높은 검색·추천 화면은 별도 경로로 분리한다.

## 경로와 책임

- `/`: API와 discovery provider를 마운트하지 않는 브랜드 홈이다. 풀스크린 홈 필름, 하나의 `h1`, 미감의 관점, 세 개의 시각 챕터, 두 개의 탐색 CTA만 제공한다.
- `/discover`: 기존 검색·추천 API, Zustand draft, TanStack Query와 Radix 탭·대화상자를 소유한다. 검색 결과는 `catalog`, 추천 결과는 `editorial` 카드를 유지한다.
- `/discover#recommend`: 비민감한 초기 탭 식별자로만 사용한다. 검색어·필터·추천 payload는 fragment, query, history state 또는 브라우저 저장소에 쓰지 않는다.
- 그 밖의 경로는 존재하지 않는 페이지임을 알리고 `/`와 `/discover` 링크를 제공한다.
- 두 경로는 실제 `<a href>` 문서 이동을 사용한다. 두 고정 경로만을 위해 라우터 의존성이나 자체 `pushState` 라우터를 추가하지 않는다.

## 홈 시각 시스템

홈은 웜 아이보리, 먹색, 석회색, 흐린 청회색과 옅은 흙색을 사용한다. 원색·네온·강한 RGB 조명과 광고 캠페인 같은 과장된 채도는 사용하지 않는다. 헤더는 부드러운 먹색, 필름 이후의 본문은 웜 페이퍼를 기본으로 하며 실제 콘텐츠보다 장식이 강해지지 않도록 한다.

새 16:9 장면 6개는 하나의 가상 미술관처럼 통일한다.

1. 오전 자연광이 길게 들어오는 조용한 전시장과 관람객 한 명
2. 반투명 천 설치 사이를 천천히 걷는 두 사람
3. 한지·도자·무광 금속이 겹친 작품의 물성 클로즈업
4. 넓은 여백 속 추상 조형물 앞에 멈춰 선 관람객의 뒷모습
5. 얇은 유리와 그림자가 겹치는 복도형 전시 공간
6. 사람이 빠져나간 뒤 빛만 남은 전시장의 엔딩 장면

모든 인물은 특정 실존 인물을 닮지 않은 가상 인물이며 뒷모습이나 작은 실루엣으로 표현한다. 실존 작품·기관·브랜드·읽을 수 있는 전시 문구·로고·워터마크를 넣지 않는다. 약한 필름 그레인, 자연스러운 재료 질감, 넓은 음영과 정돈된 여백을 공통 아트디렉션으로 사용한다.

## 홈 필름과 정적 대체

- 여섯 장면을 약 10~12초의 무음 루프로 편집한다. 움직임은 2~4%의 느린 패닝·확대와 부드러운 디졸브만 사용한다.
- 데스크톱은 MP4와 WebM source를 제공하고, 고정된 WebP poster를 항상 아래에 둔다. 영상은 `muted`, `autoPlay`, `loop`, `playsInline`, `preload="metadata"`로 제공한다.
- 영상은 장식이므로 접근성 트리에서 제외한다. `美感`, 슬로건, CTA는 이미지나 영상에 굽지 않고 HTML로 제공한다.
- `prefers-reduced-motion: reduce`에서는 video 요소를 렌더링하지 않고 poster만 표시한다. 로딩·재생 실패 때도 같은 poster가 남는다.
- 모바일은 poster 우선이며 홈의 의미와 CTA를 이해하는 데 영상이 필요하지 않아야 한다.
- 기존 v1 갈색 추상 이미지는 삭제하지 않고 기록용 원본으로 남기되 홈에서 참조하지 않는다.

## 화면 구성

홈은 `고정 헤더 → 풀스크린 필름과 h1 → 큰 관점 선언문 → 공간·사람·물성의 풀폭 시각 챕터 → 두 진입 CTA → 푸터` 순서다. 시각 챕터는 생성 이미지를 전시 사실처럼 캡션하지 않고 `공간의 온도`, `머무는 시선`, `재료의 감각`이라는 브랜드 관점으로만 설명한다.

탐색 화면은 `종이색 헤더 → 발견 페이지 h1 → 검색·추천 탭 → 결과 → 푸터` 순서다. 홈 히어로·관점·장식 챕터를 렌더링하지 않는다. 각 페이지는 `main`과 `h1`을 정확히 하나씩 가지며 skip link는 현재 페이지의 `#main-content`를 가리킨다.

## 데이터·실패·검증 경계

홈은 API를 호출하지 않고 자체 생성 로컬 자산만 사용한다. 탐색의 요청·오류·페이지 추가·늦은 응답·필수조건·확인 필요 후보·미디어 권리·텍스트 대체 계약은 변경하지 않는다. 홈 미디어는 실제 `MediaAsset`이나 전시 추천 근거와 연결하지 않는다.

자동 테스트는 경로별 렌더링, 홈 API 0회, 링크 목적지, 초기 추천 fragment, 페이지별 단일 `main`·`h1`, video 속성·poster·reduced-motion 대체와 기존 discovery 회귀를 검증한다. 브라우저 검수는 1440px·390px, `/discover` 직접 진입, 영상 실패 poster, 키보드 포커스, 가로 넘침과 reduced-motion을 확인한다.
