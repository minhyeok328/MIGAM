# 미감(美感 / MIGAM)

> 당신의 감각으로, 전시를 발견하다.

미감은 취향에 맞는 국내 전시를 찾도록 돕는 큐레이션 프로젝트입니다. 전시 기간·지역과 취향을 바탕으로 후보를 살펴보고, 각 전시를 추천하는 이유와 공식 관람 안내를 제공합니다.

## 프로젝트 소개

전시를 고를 때는 작품이나 작가뿐 아니라 관람료, 일정, 접근성, 공간의 감각적 특성도 중요합니다. 미감은 기관별로 흩어진 공식 전시 정보를 모아 이런 조건을 함께 확인할 수 있도록 합니다.

알려진 정보와 확인이 필요한 정보를 구분하고, 사용자가 꼭 필요하다고 정한 조건은 임의로 완화하지 않습니다. 방문 후보를 판단하는 데 필요한 근거를 전달하는 데 집중합니다.

## 주요 기능

전시 탐색부터 상세·관심·비교·조건별 추천까지 로컬에서 연결해 검증하고 있습니다.

- **전시·기관 검색**: 이름, 지역, 전시 상태로 관심 있는 전시와 공간을 찾습니다.
- **기간·취향별 추천**: 선택한 기간과 전시 기간이 겹치는 후보를 찾고 취향을 반영합니다. 접근성·피할 감각 자극을 필수로 선택하면 확인된 정보만 통과시킵니다.
- **추천 이유 안내**: 선택한 분위기와 확인된 전시 특성을 바탕으로 추천 이유를 설명합니다.
- **출처와 불확실성 표시**: 공식 출처와 확인 시점을 제공하고, 정보가 부족한 후보는 별도로 구분합니다.

텍스트 취향 선택, 전시·기관·작품 상세, 브라우저 관심 저장·초기화, 최대 3개 전시 비교와 외부 카카오맵 링크를 제공합니다. 실제 작품은 출처·이용 권한 심사로 수집 준비 상태이며, 키 없는 데모에는 가상 작품 4개가 있습니다. 전시 상세에는 공식 자료를 검토한 소개·볼거리·관람 안내를 표시하고 추가 확인을 위한 공식 링크를 제공합니다. 기간 검색은 개관을 보장하지 않으며 예산·예약·예상 관람시간 필터는 초기 UI에서 제외했습니다.

## 서비스 원칙

- 일반 사용자 계정이나 로그인 없이 이용하는 경험을 지향합니다.
- 원문 검색어와 추천 요청을 장기 취향 프로필이나 행동 분석에 사용하지 않습니다.
- 출처가 불분명한 사실을 추정해서 채우거나, 권리가 확인되지 않은 이미지를 표시하지 않습니다.
- 예매·결제 대행, 일정·동선 계획, 커뮤니티는 현재 제품 범위에 포함하지 않습니다.

## UI/UX 개발 상태

현재 마무리 기준은 **공개 배포 없이 로컬에서 실행하는 프로젝트**입니다. 의존성 준비 후 저장소 루트에서 다음 명령으로 실제 웹과 API를 함께 실행하고 `http://127.0.0.1:5180/`을 엽니다. 종료는 Ctrl+C입니다.

```powershell
.\backend\.venv\Scripts\python.exe -X utf8 scripts/run_local.py
```

실제 DB가 없는 환경에서는 `scripts/run_local_demo.py`로 키 없는 가상 데모를 실행할 수 있습니다. 최초 설치·데이터 준비·백업 복구·자동 브라우저 검사는 [로컬 실행 안내](docs/05-engineering/local-delivery.md), 완료 증거와 검증 제한은 [TP-010 검증 기록](docs/06-quality/tp-010-verification.md)을 참고하세요.

**현재 UI/UX는 구현 후 사용성·접근성을 검토하는 단계입니다.** API를 호출하지 않는 브랜드 홈 `/`와 검색·추천 화면 `/discover`를 분리했습니다. 검색은 기본 전시 목록을 먼저 보여주고 대상·지역·상태는 필터 패널에서 선택합니다. 제목에는 마루 부리, 본문과 조작 UI에는 SUIT를 사용합니다. 전체 P0 디자인과 사용자 흐름의 최종 승인을 뜻하지는 않습니다.

로컬 실행·키 없는 데모는 [프론트엔드 안내](frontend/README.md), 실제 전시 17건 보강과 최신 검증은 [TP-011 검증 기록](docs/06-quality/tp-011-verification.md), 초기 출시 조정은 [TP-009 검증 기록](docs/06-quality/tp-009-verification.md), 문서별 상태는 [문서 인덱스](docs/00-index.md)에서 확인할 수 있습니다.
