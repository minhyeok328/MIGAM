# 미감(美感 / MIGAM)

> 당신의 감각으로, 전시를 발견하다.

미감은 취향과 실제 관람 조건에 맞는 국내 전시를 찾도록 돕는 큐레이션 프로젝트입니다. 시각·청각·공간·상호작용에 대한 선호와 지역·날짜·예산을 함께 살펴보고, 각 전시를 추천하는 이유를 안내합니다.

## 프로젝트 소개

전시를 고를 때는 작품이나 작가뿐 아니라 관람료, 일정, 접근성, 공간의 감각적 특성도 중요합니다. 미감은 기관별로 흩어진 공식 전시 정보를 모아 이런 조건을 함께 확인할 수 있도록 합니다.

알려진 정보와 확인이 필요한 정보를 구분하고, 사용자가 꼭 필요하다고 정한 조건은 임의로 완화하지 않습니다. 방문 후보를 판단하는 데 필요한 근거를 전달하는 데 집중합니다.

## 주요 기능

현재 전시·기관 검색과 조건별 추천을 중심으로 개발하고 있습니다.

- **전시·기관 검색**: 이름, 지역, 전시 상태로 관심 있는 전시와 공간을 찾습니다.
- **관람 조건별 추천**: 날짜, 예산, 접근성, 피할 감각 자극, 예약 방식, 예상 관람시간을 반영합니다.
- **추천 이유 안내**: 선택한 분위기와 확인된 전시 특성을 바탕으로 추천 이유를 설명합니다.
- **출처와 불확실성 표시**: 공식 출처와 확인 시점을 제공하고, 정보가 부족한 후보는 별도로 구분합니다.

취향 테스트, 관심 저장, 전시 상세·비교, 지도 탐색은 후속 개발 범위입니다.

## 서비스 원칙

- 일반 사용자 계정이나 로그인 없이 이용하는 경험을 지향합니다.
- 원문 검색어와 추천 요청을 장기 취향 프로필이나 행동 분석에 사용하지 않습니다.
- 출처가 불분명한 사실을 추정해서 채우거나, 권리가 확인되지 않은 이미지를 표시하지 않습니다.
- 예매·결제 대행, 일정·동선 계획, 커뮤니티는 현재 제품 범위에 포함하지 않습니다.

## UI/UX 개발 상태

**현재 UI/UX는 검색·추천 기능과 API 연동을 확인하기 위한 임시 구현입니다.** 최종 디자인, 화면 구성, 사용자 흐름은 아직 확정되지 않았으며 사용성·접근성 검토를 거쳐 변경할 예정입니다.
