# 미감(美感 / MIGAM)

> 당신의 감각으로, 전시를 발견하다.

미감은 취향에 맞는 국내 전시를 발견하고, 관람에 필요한 정보를 살펴볼 수 있는 전시 탐색 웹 프로젝트입니다. 지역과 전시 기간, 좋아하는 분위기를 바탕으로 전시를 찾고 관심 있는 전시를 저장하거나 비교할 수 있습니다.

## 프로젝트 소개

전시를 보고 싶어도 어떤 전시가 나에게 맞는지 고르기는 쉽지 않습니다. 미감은 작가나 미술 사조를 잘 몰라도 차분함, 몰입감, 빛과 소리처럼 자신이 좋아하는 경험에서 탐색을 시작할 수 있도록 만들었습니다.

기관별로 흩어진 공식 정보를 모아 전시의 소개와 볼거리, 확인된 관람 안내를 제공합니다. 추천 이유와 정보의 출처를 함께 보여주어 사용자가 자신의 취향과 상황에 맞춰 관람할 전시를 선택하도록 돕습니다. React와 Django를 연결해 로컬 환경에서 이용할 수 있도록 구현했습니다.

## 주요 기능

- **전시 둘러보기**: 전시명·기관명으로 검색하고 지역과 전시 상태로 목록을 좁힙니다.
- **기간·취향별 추천**: 선택한 기간과 전시 기간이 겹치는 후보에 취향을 반영하고, 추천 이유를 안내합니다.
- **전시 상세**: 전시 소개·볼거리·기간·장소와 확인된 관람료·운영시간을 살펴봅니다. 공식 안내와 외부 카카오맵으로도 연결합니다.
- **관심 저장과 비교**: 관심 있는 전시를 저장하고 최대 3개의 전시를 나란히 비교합니다.
- **내 취향 관리**: 직접 선택한 취향을 브라우저에 저장해 추천에 반영하고, 저장한 데이터를 초기화할 수 있습니다.
- **접근성·감각 조건**: 필요한 접근성이나 피하고 싶은 감각 자극을 선택하면 해당 조건이 확인된 전시만 추천합니다.

## 데이터와 개인정보 원칙

- **공식 출처와 확인 시점**을 함께 제공하며, 확인되지 않은 관람 정보를 추정해 채우지 않습니다. 전시 기간의 일치와 실제 개관 여부도 구분합니다.
- **일반 사용자 로그인 없이** 이용합니다. 직접 저장한 관심·취향은 해당 브라우저에 보관하고 검색어·추천 요청은 장기 프로필이나 행동 분석에 사용하지 않습니다.
- **이용 권한이 확인된 이미지**만 표시하며, 외부 전시 정보와 미디어의 권리를 존중합니다.
